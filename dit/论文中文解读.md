## 一、一句话结论

扩散模型的去噪主干长期默认是卷积 U-Net。DiT（Diffusion Transformer）把它换成标准的 Vision Transformer：先用一个**冻结的现成 VAE** 把图像压成 latent，再把 latent 切成 $p\times p$ 的小块（patch）排成 token 序列，由 $N$ 个 DiT block 预测噪声（和对角协方差）。时间步与类别标签通过 adaptive layer norm（adaLN）注入，并把每个 block 的残差分支初始化成恒等映射（adaLN-Zero），这是四种条件注入方案里最好的一种。

论文的核心发现是**缩放规律**：用前向 Gflops（而不是参数量）衡量模型复杂度，Gflops 越高（更深更宽，或 patch 更小、token 更多），FID 越低，二者的相关系数约为 $-0.93$。最大的 DiT-XL/2（118.6 Gflops）在类条件 ImageNet 256×256 上，用 classifier-free guidance（$s=1.5$）取得 FID-50K 2.27，比此前最好的扩散模型（LDM-4-G，3.60）低；在 512×512 上取得 3.04，比此前最好的扩散模型（ADM-G + ADM-U，3.85）低。

## 二、背景与前置知识

### 2.1 论文要回答的问题（原文第 1–2 页）

过去五年，自然语言处理、视觉等领域的网络结构几乎都被 Transformer 取代；但图像级的生成模型里，Transformer 主要出现在自回归模型中。扩散模型是图像生成的前沿，却全都沿用卷积 U-Net 作为事实上的主干：Ho 等人（DDPM）最早引入 U-Net 主干，它继承自 PixelCNN++，是以 ResNet 块为主的卷积结构，并在较低分辨率处插入了空间自注意力块（这是它与标准 U-Net 的区别）；Dhariwal 与 Nichol 对 U-Net 的结构做过消融（例如用 adaptive normalization 层注入条件信息，调整卷积通道数），但 U-Net 的高层设计基本没变。

本文要“祛魅”：**U-Net 的归纳偏置对扩散模型的性能并不关键，它可以被标准的 Transformer 设计直接替换**。好处是扩散模型可以受益于“架构统一”的趋势：继承其他领域的最佳实践和训练配方，并保留可扩展性、鲁棒性与效率，还为跨领域研究提供标准化架构。DiT 遵循 ViT 的最佳实践，ViT 在视觉识别上比传统卷积网络（如 ResNet）扩展得更有效。

论文具体研究 Transformer 的**缩放行为**：网络复杂度（用 Gflops 度量）与样本质量（用 FID 度量）的关系。做法是在 Latent Diffusion Models（LDM）的框架下构建并评测 DiT 设计空间（扩散模型在 VAE 的潜空间中训练），从而成功地把 U-Net 换成 Transformer；并表明 DiT 是可扩展的扩散架构：网络复杂度与样本质量之间有很强的相关性。

### 2.2 前置知识 1：扩散模型的公式与损失（原文 3.1 节，第 3 页）

本节回顾理解 DiT 所需的 DDPM 概念，详细推导见 [DDPM](../ddpm/论文中文解读.md)。

**前向加噪**：高斯扩散模型假设一个逐步给真实数据 $x_0$ 加噪声的前向过程，其中常数 $\bar\alpha_t$ 是超参数：

$$
q(x_t\mid x_0)=\mathcal N\big(x_t;\sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)\mathbf I\big),\qquad x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon_t,\quad \epsilon_t\sim\mathcal N(0,\mathbf I).
$$

**反向过程与训练**：扩散模型学习逆转前向破坏的反向过程 $p_\theta(x_{t-1}\mid x_t)=\mathcal N\big(\mu_\theta(x_t),\Sigma_\theta(x_t)\big)$，用神经网络预测 $p_\theta$ 的统计量。反向过程模型用对数似然的变分下界训练，去掉与训练无关的一项后化为

$$
\mathcal L(\theta)=-\log p(x_0\mid x_1)+\sum_t D_{\mathrm{KL}}\big(q^*(x_{t-1}\mid x_t,x_0)\,\Vert\,p_\theta(x_{t-1}\mid x_t)\big).
$$

（原文此处把第一项写成 $-p(x_0\mid x_1)$，漏了对数，对照 DDPM 的式（5）应为 $-\log p(x_0\mid x_1)$。）由于 $q^*$ 与 $p_\theta$ 都是高斯，KL 散度可由两个分布的均值与协方差算出。把 $\mu_\theta$ 重参数化为噪声预测网络 $\epsilon_\theta$，就可以用预测噪声 $\epsilon_\theta(x_t)$ 与真实采样噪声 $\epsilon_t$ 之间的简单均方误差训练：

$$
\mathcal L_{\mathrm{simple}}(\theta)=\big\lVert\epsilon_\theta(x_t)-\epsilon_t\big\rVert_2^2.
$$

**学习协方差**：若要训练带有**学习到的**反向过程协方差 $\Sigma_\theta$ 的模型，则需要优化完整的 KL 项。本文沿用 Nichol 与 Dhariwal 的做法：**用 $\mathcal L_{\mathrm{simple}}$ 训练 $\epsilon_\theta$，用完整的 $\mathcal L$ 训练 $\Sigma_\theta$**。这就是 DiT 的输出同时包含噪声预测和对角协方差预测的原因。训练好之后，从 $x_{t_{\max}}\sim\mathcal N(0,\mathbf I)$ 出发，通过重参数化技巧反复采样 $x_{t-1}\sim p_\theta(x_{t-1}\mid x_t)$ 就得到新图像。

### 2.3 前置知识 2：classifier-free guidance（原文 3.1 节，第 4 页）

条件扩散模型把额外信息（如类别标签 $c$）作为输入，此时反向过程变成 $p_\theta(x_{t-1}\mid x_t,c)$，$\epsilon_\theta$ 与 $\Sigma_\theta$ 都以 $c$ 为条件。Classifier-free guidance 用来鼓励采样过程找到使 $\log p(c\mid x)$ 很高的 $x$。由 Bayes 公式 $\log p(c\mid x)\propto\log p(x\mid c)-\log p(x)$，所以 $\nabla_x\log p(c\mid x)\propto\nabla_x\log p(x\mid c)-\nabla_x\log p(x)$。把扩散模型的输出解释为 score 函数，DDPM 采样可以被引导去采样 $p(x\mid c)$ 很高的 $x$：

$$
\hat\epsilon_\theta(x_t,c)=\epsilon_\theta(x_t,\varnothing)+s\cdot\nabla_x\log p(x\mid c)\ \propto\ \epsilon_\theta(x_t,\varnothing)+s\cdot\big(\epsilon_\theta(x_t,c)-\epsilon_\theta(x_t,\varnothing)\big),
$$

其中 $s>1$ 表示引导强度（$s=1$ 就是标准采样）。要得到 $c=\varnothing$ 时的预测，训练时**随机丢弃** $c$，并用一个**学习到的“空”嵌入** $\varnothing$ 替换它。原文说 classifier-free guidance 能显著改善样本，这一趋势在 DiT 上同样成立。（丢弃概率原文没有给出。）

**读法**：同一个网络，一次带条件、一次不带条件，两次预测的差给出“更像类别 $c$”的方向，再乘以 $s$ 外推；$s$ 越大越贴合类别、多样性越低（附录 B 也指出这一点）。

### 2.4 前置知识 3：latent diffusion 模型（原文 3.1 节，第 4 页）

直接在高分辨率像素空间训练扩散模型计算上代价过高。Latent diffusion models（LDM，见 [Latent Diffusion](../latent_diffusion/论文中文解读.md)）用两阶段方法解决：(1) 学习一个自编码器，用学到的编码器 $E$ 把图像压成更小的空间表示；(2) 训练表示 $z=E(x)$ 的扩散模型，而不是图像 $x$ 的扩散模型（$E$ 冻结）。采样时先从扩散模型采样一个表示 $z$，再用学到的解码器 $x=D(z)$ 解码成图像。

如图 2 所示，LDM 用像素空间扩散模型（如 ADM）的一小部分 Gflops 就获得不错的性能。因为本文关心计算效率，这使 LDM 成为架构探索的有吸引力的起点。本文把 DiT 用在潜空间，不过它们也可以不加修改地用于像素空间。这使得整套图像生成流水线是**混合式**的：现成的卷积 VAE 加上基于 Transformer 的 DDPM。

### 2.5 为什么用 Gflops 而不是参数量衡量复杂度（原文第 2–3 页）

在图像生成文献里，常用参数量评估架构复杂度。但参数量往往是模型复杂度的差劲代理，因为它没有考虑例如图像分辨率这类显著影响性能的因素。因此本文的复杂度分析主要通过**理论 Gflops**，这也与架构设计文献里常用 Gflops 衡量复杂度的做法一致（原文也承认“黄金复杂度指标”仍有争议，因为它常取决于具体应用场景）。与本文最相关的是 Nichol 与 Dhariwal 改进扩散模型的工作，他们分析过 U-Net 架构类的可扩展性与 Gflops 性质；本文则聚焦 Transformer 类。

## 三、方法：DiT 的设计空间

论文要尽量忠实于标准 Transformer 架构，以保留其缩放性质。DiT 基于 ViT（在 patch 序列上运算），保留了 ViT 的许多最佳实践。整个设计空间包含三个维度：**patch size**、**Transformer block 架构**、**模型尺寸**。

### 3.1 整体结构与一次前向的数据流（图 3 左）

*图 3（原文 Figure 3，第 3 页）：Diffusion Transformer（DiT）的架构。左：我们训练条件潜空间 DiT 模型。输入 latent 被分解成 patch，由若干 DiT block 处理。右：DiT block 的细节。我们试验了标准 Transformer block 的几种变体，分别通过 adaptive layer norm、交叉注意力和额外的输入 token 来引入条件。Adaptive layer norm 效果最好。*

**图中文字翻译与读法**：

- **最左：Latent Diffusion Transformer（潜扩散 Transformer）**。自下而上：Noised Latent（带噪 latent，32×32×4）经 Patchify（切块并线性嵌入）变成 token；Timestep $t$（时间步）与 Label $y$（类别标签）经 Embed（嵌入）变成条件向量；二者进入 “N × DiT Block”（重复 $N$ 次的 DiT block）；随后是 Layer Norm、Linear and Reshape（线性层并重排），得到两个输出：Noise（噪声预测，32×32×4）与 $\Sigma$（对角协方差预测，32×32×4）。
- **中：DiT Block with adaLN-Zero（带 adaLN-Zero 的 DiT block）**，本文最终采用的 block。底部是 Input Tokens（输入 token）与 Conditioning（条件，即 $t$ 与 $y$ 的嵌入之和），条件经过一个 MLP 回归出 $\gamma_1,\beta_1,\alpha_1,\gamma_2,\beta_2,\alpha_2$。自下而上：Input Tokens → Layer Norm → Scale, Shift（用 $\gamma_1,\beta_1$ 调制）→ Multi-Head Self-Attention（多头自注意力）→ Scale（用 $\alpha_1$ 缩放）→ 与输入的残差相加 “+”；再 → Layer Norm → Scale, Shift（$\gamma_2,\beta_2$）→ Pointwise Feedforward（逐位置前馈网络）→ Scale（$\alpha_2$）→ 残差相加 “+”。
- **右两个半透明的 block** 是被淘汰的方案。DiT Block with Cross-Attention（交叉注意力 block）：多头自注意力之后再接一个多头交叉注意力（条件作为 key/value），然后是 Pointwise Feedforward，每个子层前有 Layer Norm、后有残差相加。DiT Block with In-Context Conditioning（上下文条件 block）：条件在序列维度上与输入 token 拼接（Concatenate on Sequence Dimension），之后就是标准的 ViT block（Layer Norm → 多头自注意力 → 残差 → Layer Norm → 前馈 → 残差）。
- **读图结论**：三种方案的区别只在“条件 $t,y$ 如何进入 Transformer block”；原文在图题里已给出结论：adaLN（尤其 adaLN-Zero）效果最好（见 5.1 节）。

**一次前向的形状变化**（本文以 DiT-XL/2、256×256 图像为例整理；$d$、头数见表 1，头维度 72 由 $d$ 与头数相除得到）：

|---|---|
| 输入 latent $z_t$ | 32×32×4 |
| Patchify（$p=2$，线性嵌入）+ 位置嵌入 | 256 个 token，每个 1152 维 |

### 3.2 Patchify：把 latent 变成 token 序列（原文第 4 页，图 4）

DiT 的输入是一个空间表示 $z$（对 256×256×3 的图像，$z$ 的形状为 32×32×4）。DiT 的第一层是 “patchify”：对输入里的每个 patch 做线性嵌入，把空间输入转成由 $T$ 个 token 组成的序列，每个 token 是 $d$ 维。patchify 之后，对所有输入 token 加上标准的 ViT 基于频率的位置嵌入（sine-cosine 版本）。patchify 产生的 token 数 $T$ 由 patch size 超参数 $p$ 决定。

![图 4：DiT 的输入规格](rendered_figures/fig4-patchify.png)

*图 4（原文 Figure 4，第 4 页）：DiT 的输入规格。给定 patch size $p\times p$，形状为 $I\times I\times C$ 的空间表示（来自 VAE 的带噪 latent）被“patchify”成长度 $T=(I/p)^2$、隐层维度为 $d$ 的序列。更小的 patch size $p$ 得到更长的序列，因而有更多 Gflops。*

**图中文字翻译与读法**：下方是 Noised Latent（带噪 latent，$I\times I\times C$），被划成 $p\times p$ 的小方块（图中示意 4×4=16 块，每块边长 $p$）；上方是 Input Tokens（输入 token，$T\times d$）：16 个方块依次排成一条序列，长度 $T=(I/p)^2$，再送入 DiT Block。读图结论：序列长度 $T$ 随 $p$ 的平方反比变化。

**token 数与 Gflops**（原文）：把 $p$ 减半，$T$ 变成四倍，因此总的 Transformer Gflops 至少变成四倍。虽然 $p$ 对 Gflops 影响很大，但改变 $p$ 对下游参数量**没有实质影响**。本文把 $p=2,4,8$ 加入 DiT 设计空间。对 $I=32$（256×256 图像）：

| patch size $p$ | 8 | 4 | 2 |
|---|---:|---:|---:|
| token 数 $T=(32/p)^2$ | 16 | 64 | 256 |

对 512×512 图像，latent 是 64×64×4，$p=2$ 时共有 1024 个 token（原文第 5.1 节）。

### 3.3 DiT block：四种条件注入方案（原文 3.2 节，第 4–5 页）

patchify 之后，输入 token 由一串 Transformer block 处理。除了带噪图像输入，扩散模型有时还要处理额外的条件信息，如噪声时间步 $t$、类别标签 $c$、自然语言等。论文探索四种以不同方式处理条件输入的 Transformer block 变体，它们对标准 ViT block 做了小而重要的改动：

1. **In-context conditioning（上下文条件）**：直接把 $t$ 与 $c$ 的向量嵌入当作**两个额外 token** 追加到输入序列里，与图像 token 一视同仁。这类似 ViT 里的 cls token，使得可以不加修改地使用标准 ViT block；最后一个 block 之后把条件 token 从序列中移除。这种方法引入的新增 Gflops 可以忽略不计。
2. **Cross-attention block（交叉注意力）**：把 $t$ 与 $c$ 的嵌入拼成一个长度为 2 的序列，与图像 token 序列**分开**。Transformer block 被修改为在多头自注意力块之后再加一个多头交叉注意力层，类似 Vaswani 等的原始设计，也类似 LDM 对类别标签做条件时用的做法。交叉注意力给模型增加的 Gflops 最多，约 15% 的开销。
3. **Adaptive layer norm（adaLN）block**：沿用 GAN 与带 U-Net 主干的扩散模型里广泛使用的 adaptive normalization 层，把 Transformer block 里标准的 layer norm 换成 adaLN。不直接学习逐维度的缩放与平移参数 $\gamma,\beta$，而是由 $t$ 与 $c$ 的嵌入向量**之和**回归出它们。三种 block 里 adaLN 增加的 Gflops 最少，所以计算最高效；它也是唯一一种受限于“对所有 token 施加同一函数”的条件机制。
4. **adaLN-Zero block**：已有关于 ResNet 的工作发现，把每个残差块初始化为恒等函数是有益的。例如 Goyal 等发现，把每个块里最后一个 batch norm 的缩放因子 $\gamma$ 零初始化，能加速监督学习中的大规模训练；扩散 U-Net 也用类似的初始化策略，把每个块里在残差连接之前的最后一层卷积零初始化。本文对 adaLN block 做同样的改动：除了回归 $\gamma,\beta$，还回归**逐维度的缩放参数 $\alpha$**，把它施加在 DiT block 内**每个残差连接之前**。**把生成这些参数的 MLP 初始化为对所有 $\alpha$ 输出零向量**，于是整个 DiT block 在初始化时就是恒等函数。与普通 adaLN 一样，adaLN-Zero 增加的 Gflops 可以忽略不计。

**adaLN-Zero 的公式**（补充：根据图 3 中间图整理；原文没有写公式）。记条件向量 $c=\mathrm{Embed}(t)+\mathrm{Embed}(y)$，由 MLP 得到 $(\gamma_1,\beta_1,\alpha_1,\gamma_2,\beta_2,\alpha_2)=\mathrm{MLP}(c)$（每个都是 $d$ 维），则对输入 token $x$：

$$
x'=x+\alpha_1\odot\mathrm{MSA}\big(\gamma_1\odot\mathrm{LN}(x)+\beta_1\big),\qquad
x_{\mathrm{out}}=x'+\alpha_2\odot\mathrm{FFN}\big(\gamma_2\odot\mathrm{LN}(x')+\beta_2\big).
$$

其中 $\mathrm{LN}$ 是不带可学习仿射参数的 layer norm（这一点是本文的合理推断；原文只说“回归 $\gamma,\beta$ 来替代直接学习的缩放与平移”），$\mathrm{MSA}$ 是多头自注意力，$\mathrm{FFN}$ 是逐位置前馈网络，$\odot$ 是逐维度乘法，$\gamma,\beta,\alpha$ 对**所有 token 共享**（对整张图一份）。**读法**：$\alpha_1=\alpha_2=0$ 时两个残差分支都被“关掉”，$x_{\mathrm{out}}=x$，即整个 block 是恒等映射；训练过程中 $\alpha$ 才逐渐变成非零，条件信息也通过 $\gamma,\beta,\alpha$ 同时调制归一化与残差强度。附录 A 给出的实现细节是：时间步先经 256 维频率嵌入再过一个两层 MLP（宽度等于 Transformer 隐层大小，SiLU 激活）；每个 adaLN 层把时间步嵌入与类别嵌入之和送入 SiLU 非线性与一个线性层，线性层输出神经元数是 Transformer 隐层大小的 **4 倍（adaLN）或 6 倍（adaLN-Zero）**；核心 Transformer 用 GELU（tanh 近似）。

**四种方案的参数量与 Gflops 对照**（取自表 4，均为 DiT-XL/2、256×256；FID-50K 为 400K 训练步、无 guidance）：

| block 类型 | Gflops | 参数量（M） | FID-50K |
|---|---:|---:|---:|
| In-context | 119.37 | 449 | 35.24 |
| Cross-attention | 137.62 | 598 | 26.14 |
| adaLN | 118.56 | 600 | 25.21 |
| adaLN-Zero | 118.64 | 675 | **19.47** |

**本文核算：参数量为什么是这样**。一个标准 Transformer block 约有 $12d^2$ 个参数（注意力的 $Q,K,V,O$ 共 $4d^2$，MLP 取 4 倍扩张共 $8d^2$）。对 DiT-XL（$d=1152$，$N=28$）：$12d^2N\approx446$M，正是 in-context 的 449M（它没有额外模块）。cross-attention 每块多一个交叉注意力（约 $4d^2$），总计约 $16d^2N\approx595$M，对应 598M；adaLN 每块多一个输出 $4d$ 的调制 MLP（约 $4d^2$），同样约 595M，对应 600M；adaLN-Zero 的调制 MLP 输出 $6d$（约 $6d^2$），约 $18d^2N\approx669$M，对应 675M。所以 adaLN-Zero 比 adaLN 多出的约 75M 参数，来自多出的 $\alpha_1,\alpha_2$ 输出。这一点在评价“零初始化的作用”时要记得（见第六节）。

### 3.4 模型尺寸（原文表 1，第 5 页）

沿用 ViT 的做法，用标准的 Transformer 配置，同时缩放层数 $N$、隐层维度 $d$ 与注意力头数。共四种配置 DiT-S、DiT-B、DiT-L、DiT-XL，覆盖很宽的模型尺寸和 Gflops 分配范围，从 0.3 到 118.6 Gflops（表 4 中最小的 DiT-S/8 为 0.36），便于考察缩放表现。

下表给出 DiT 各配置的细节：遵循 ViT 的模型配置，Small（S）、Base（B）、Large（L）；另外引入一个 XLarge（XL）配置作为最大模型。Gflops 一列在 $I=32$、$p=4$ 下计算。

| 模型 | 层数 $N$ | 隐层维度 $d$ | 注意力头数 | Gflops（$I=32$，$p=4$） |
|---|---:|---:|---:|---:|
| DiT-S | 12 | 384 | 6 | 1.4 |
| DiT-B | 12 | 768 | 12 | 5.6 |
| DiT-L | 24 | 1024 | 16 | 19.7 |
| DiT-XL | 28 | 1152 | 16 | 29.1 |

（原文表 1，第 5 页。）模型命名为“配置 / patch size”，例如 DiT-XL/2 表示 XLarge 配置、$p=2$。

**本文核算：Gflops 的解析公式**。原文没有给公式，但可以用 $N,d,T$ 近似复现表 4（偏差小于 1%，见下）。对 DiT block 数 $N$、隐层维度 $d$、token 数 $T$：

$$
\text{Gflops}\approx\frac{1}{10^{9}}\Big[\,N\,T\,\big(12d^2+2Td\big)+6d^2N\,\Big],
$$

其中 $12d^2T$ 是每层的线性层（注意力投影 $4d^2$ 加 MLP $8d^2$，每个 token 一份），$2T^2d$ 是注意力的 $QK^\top$ 与加权求和两次矩阵乘，$6d^2N$ 是 adaLN-Zero 的调制 MLP（对整张图只算一次），patchify 与最后的线性层贡献很小（可忽略）。这里数的是乘加次数（每次乘加记一次），这也是视觉论文里常见的 “flops” 口径。

核对：DiT-XL/2（$N=28,d=1152,T=256$）：线性层与注意力共约 118.38 G，加调制 MLP 约 0.22 G，得到约 118.6 G（表 4：118.64）；DiT-S/2（$N=12,d=384,T=256$）约 6.06 G（表 4：6.06）；DiT-XL/8（$T=16$）约 7.39 G（表 4：7.39）；512×512 的 DiT-XL/2（$T=1024$）约 524.5 G（表 4：524.60）。按这个公式计算全部 12 个 256×256 模型，与表 4 的偏差都小于 1%，其中 9 个小于 0.1%（偏差较大的是 DiT-S/8 约 0.7%、DiT-B/8 约 0.3%、DiT-S/4 约 0.1%，主要是表中数字只保留两位小数所致）。

两个推论：(1) $p$ 减半时 $T$ 变成 4 倍，线性层部分恰好变成 4 倍，注意力部分变成 16 倍，总计“至少 4 倍”（原文的说法）；(2) 在 $T=256$ 时，注意力的矩阵乘只占 DiT-XL/2 总 Gflops 的约 3.6%（约 4.2 G / 118.4 G），Gflops 增长主要来自**与 token 数成正比的线性层**，而不是注意力本身。

### 3.5 Transformer 解码器（原文第 5 页）

最后一个 DiT block 之后，要把图像 token 序列解码成输出的噪声预测和输出的对角协方差预测，二者的形状都等于原始空间输入。用一个标准的**线性解码器**完成：先施加最后的 layer norm（若用 adaLN 则是自适应的），再把每个 token 线性解码成一个 $p\times p\times2C$ 的张量（$C$ 是 DiT 空间输入的通道数），最后把解码出的 token 重排回原始空间布局，得到预测的噪声和协方差。完整的 DiT 设计空间就是 patch size、Transformer block 架构与模型尺寸。

### 3.6 补充：训练与采样的完整流程

原文没有给算法框，下面是根据第 3、4 节和附录 A 整理的流程（标 “原文未给” 的部分是实现细节，需对照官方代码）：

```text
准备：冻结的 VAE（编码器 E、解码器 D）；DiT 网络 f_θ(z_t, t, y) → (ε_θ, Σ_θ)

训练（一次迭代，batch=256）：
    取图像 x 与类别 y，随机水平翻转
    z = E(x)                               （latent 的缩放常数：原文未给）
    以一定概率把 y 换成可学习的 "空" 嵌入 ∅    （丢弃概率：原文未给）
    t ~ Uniform{1, ..., 1000}，ε ~ N(0, I)
    z_t = √ᾱ_t · z + √(1−ᾱ_t) · ε
    (ε_θ, Σ_θ) = f_θ(z_t, t, y)
    损失：ε_θ 用 ‖ε − ε_θ‖²（L_simple）训练；Σ_θ 用完整的 L（KL 项）训练
    AdamW 更新，学习率常数 1e-4；同时维护 EMA（衰减 0.9999）

采样：
    z_{t_max} ~ N(0, I)
    对 t 从大到小（评测用 250 个 DDPM 步）：
        ε̂ = ε_θ(z_t, ∅) + s · ( ε_θ(z_t, y) − ε_θ(z_t, ∅) )       （使用 guidance 时；原文只对前 3 个 latent 通道做 guidance）
        用 ε̂ 与 Σ_θ 按 DDPM 的反向步骤得到 z_{t-1}
    x = D(z_0)
```

### 5.3 更大的 DiT 模型对算力的利用更高效（原文第 8 页，图 9）

原文把训练算力估计为

$$
\text{训练算力}\approx\text{模型 Gflops}\times\text{批大小}\times\text{训练步数}\times3,
$$

其中因子 3 粗略地把反向传播当作前向的两倍计算量。（本文核算：DiT-XL/2 训练 400K 步约 $3.6\times10^{10}$ Gflops，训练 7M 步约 $6.4\times10^{11}$ Gflops，与图 9 横轴的右端相符。）

### 5.5 模型算力与采样算力（原文 5.2 节，第 9 页，图 10）

扩散模型的独特之处在于，训练之后还可以通过增加采样步数来使用更多算力。既然模型 Gflops 对样本质量影响这么大，本节研究：更小模型算力的 DiT 能否通过更多的**采样算力**超过更大的 DiT。作者在 400K 训练步后，对全部 12 个 DiT 模型用 [16, 32, 64, 128, 256, 1000] 步采样计算 FID-10K（图 10）。

![图 10：增加采样算力无法弥补模型算力的不足](rendered_figures/fig10-sampling-compute.png)

*图 10（原文 Figure 10，第 9 页）：增加**采样**算力无法弥补**模型**算力的不足。对每个训练了 400K 迭代的 DiT 模型，用 [16, 32, 64, 128, 256, 1000] 个采样步计算 FID-10K。对每个步数，画出 FID 以及采样每张图所用的 Gflops。小模型即使采样时用的测试期 Gflops 比大模型还多，也无法缩小与大模型的性能差距。*

**图中文字翻译与读法**：横轴 Sampling Compute (Gflops)（采样一张图所用的总 Gflops = 模型 Gflops × 采样步数，对数刻度），纵轴 FID-10K（越低越好）。每个模型一条线，线上 6 个点自左向右依次是 16、32、64、128、256、1000 步。读图：(1) 每条线先陡降后变平，说明采样步数增加到一定程度后收益很小；(2) 小模型即使采样到 1000 步也停在较高的 FID 平台（从图上读出的近似值：S/8 约 148、S/4 约 96、S/2 约 66、XL/8 约 102），而 L/2 与 XL/2 的平台约 20–25，小模型无论怎样增加采样算力都到不了这个水平。

**原文的对比**：考虑 DiT-L/2 用 1000 采样步、DiT-XL/2 用 128 步。此时 L/2 采样每张图用 80.7 Tflops；XL/2 少用 5 倍的算力，只需 15.2 Tflops，却有更好的 FID-10K（**23.7 对 25.9**）。结论：**增加采样算力不能弥补模型算力的不足**。（本文核算：$80.71\times1000\,\text{Gflops}=80.7$ Tflops，$118.64\times128=15.2$ Tflops，比值约 5.3。）

**只对前三个 latent 通道做 guidance（附录 A）**。在使用 classifier-free guidance 的实验里，作者只对 latent 的**前三个通道**施加 guidance，而不是全部四个通道。作者调查后发现，三通道 guidance 与四通道 guidance 给出相似的结果（FID），只需要调整尺度因子：三通道、尺度 $(1+x)$ 大致可由四通道、尺度 $(1+\tfrac34x)$ 近似（例如三通道尺度 1.5 给出 FID-50K 2.27，而四通道尺度 1.375 给出 FID-50K 2.20）。作者认为只对元素的子集施加 guidance 仍能取得好性能“有些有趣”，留待未来探索。这意味着表 2 中 2.27 这个头条数字用的是三通道 guidance，并非最低的设置。

## 六、局限、证据边界与常见误读

**原文自己交代的方向**：结论里作者说，鉴于有希望的缩放结果，未来工作应继续把 DiT 扩展到更大的模型和更多的 token 数；DiT 还可以作为 DALL·E 2、Stable Diffusion 这类文本到图像模型的**即插即用主干**来探索——也就是说本文**没有**做文本到图像。

**证据边界（读数字时注意）**：

- **只有类条件 ImageNet，且 VAE 固定**：所有结论都是在 Stable Diffusion 的现成 VAE 潜空间里、在 ImageNet 类条件生成上得到的。条件只有“时间步 + 类别标签”这类**全局**条件；adaLN 是“对所有 token 施加同一函数”的机制，是否适用于文本等序列条件，本文没有验证。
- **“DiT 优于 U-Net”的比较不是同等训练预算下的对照**：本文的缩放实验只在 DiT 内部做；与 ADM、LDM 的比较用的是它们已发表的数字。原文用推断时的 Gflops 来论证“计算高效”，没有给出同等训练算力下的对照。按两篇论文各自报告的数字估算（本文核算），DiT-XL/2 的 7M 步、批大小 256 约见过 17.9 亿个样本，LDM-4 的 178K 步、批大小 1200（LDM 论文表 10）约 2.1 亿个，相差约 8 倍。原文还说 DiT-XL/2 的 FID 没有饱和、是尽可能长地训练的。
- **不加 guidance 的差距小**：DiT-XL/2（9.62）与 LDM-4（10.56）、ADM（10.94）相差约 1；级联模型 ADM-U（7.49）、CDM（4.88）还更好。2.27 对 3.60 的领先出现在 cfg=1.5 下，并且 guidance 只用在 latent 的前三个通道，换成四通道是 2.20（附录 A）。
- **512×512 上并未超过 StyleGAN-XL**：FID 3.04 对 2.41，sFID 5.02 对 4.06，IS 240.82 对 267.75（表 3）；256×256 上 FID 的领先也很窄（2.27 对 2.30），sFID 则落后于 StyleGAN-XL（4.60 对 4.02），Precision 低于 BigGAN-deep 与 LDM-4-G（0.83 对 0.87）；IS（278.24 对 265.12）与 Recall（0.57 对 0.53）仍高于 StyleGAN-XL。原文的措辞是“优于所有此前的**扩散**模型”，对 256×256 另说“所有此前生成模型里 FID 最低”。
- **adaLN 与 adaLN-Zero 的差异不止是初始化**：原文把 adaLN-Zero 优于 adaLN（19.47 对 25.21）归因于“初始化”，但两者还差一组 $\alpha$ 缩放参数（参数量 600M 对 675M，见 3.3 节核算），原文没有“带 $\alpha$ 但不用零初始化”的对照，所以“初始化是关键”这一结论只能说有提示、未被单独验证。
- **Gflops 是理论前向计算量，且不含 VAE**：表 4 注明参数与 Gflops 都排除 VAE（84M 参数）；用它衡量“计算高效”不等于实际耗时（实际还取决于硬件、注意力实现、批大小等）；采样总算力还要乘以采样步数。
- **相关系数是在对数 Gflops 上算的**（本文用表 4 复核：对数 Gflops 为 $-0.93$，原始 Gflops 为 $-0.73$）；只有 12 个点，且 Gflops 通过改变深度宽度与 $p$ 两种方式共同变化，原文没有拟合缩放定律的幂指数。
- **没有方差**：表格里的 FID 都是单次评测的数字，没有给出多次训练/采样的方差或置信区间；表 2 的 FID 对解码器选择约有 0.2 的差异（表 5）。
- **FID 受实现影响**：原文强调全部数字用 ADM 的 TensorFlow 评估套件算出；与其他论文的数字比较时要核对评测实现、样本数与参考集。图 10 用的是 FID-10K，与 FID-50K 不可直接比较。
- **精选样本**：图 1 与附录图 11 是挑选过的，质量判断应看附录里的未挑选样本（图 14–33）。

**常见误读**：

- DiT 证明 Transformer 是有效且可扩展的扩散骨干，**不是**证明 U-Net 已经无效，也不是说“Transformer 一定比卷积好”；它仍然依赖 VAE 潜空间、扩散目标和采样过程，生成能力不能只归于自注意力。
- “缩放”在这里指 **Gflops**（深度、宽度或 token 数），不是单纯的参数量：patch size 变小时参数量几乎不变，但 FID 大幅下降。
- DiT-XL/2 里的 “XL/2” 是配置 XL 加 patch size 2，不是“2 倍”的意思。
- 论文不涉及文本条件与视频；后来采用 DiT 类主干的系统（如 Stable Diffusion 3、Sora）是后续工作，不在本文内。

## 七、复现检查清单

- VAE 与 latent：使用同一个现成 VAE（缩放分析用 ft-MSE 解码器，最终指标用 ft-EMA 解码器）；latent 的缩放常数原文未给，必须与所用 VAE 的官方约定一致；VAE 不计入参数量与 Gflops。
- DiT block：adaLN-Zero，调制 MLP 输出 $6d$ 个数（$\gamma_1,\beta_1,\alpha_1,\gamma_2,\beta_2,\alpha_2$）；$\alpha$ 零初始化使每个 block 初始为恒等；最后一层线性层零初始化；位置嵌入是固定的 sine-cosine；GELU 用 tanh 近似。
- 输出：每个 token 输出 $p\times p\times2C$，重排后切成噪声预测和对角协方差；$\epsilon_\theta$ 用 $\mathcal L_{\mathrm{simple}}$ 训练，$\Sigma_\theta$ 用完整的 $\mathcal L$ 训练（沿用 ADM 的协方差参数化）。
- 训练：AdamW，常数学习率 $1\times10^{-4}$，无 weight decay，批大小 256，只做水平翻转，不用 warmup；EMA 衰减 0.9999，评测用 EMA 权重；扩散步数 1000、线性 $\beta$ 从 $1\times10^{-4}$ 到 $2\times10^{-2}$。
- classifier-free guidance：训练时随机把类别替换为可学习的空嵌入（丢弃概率原文未给）；采样时只对前 3 个 latent 通道做 guidance；记录 $s$（表 2 为 1.25 与 1.5，图 11 为 4.0 与 6.0）。
- 评测：FID-50K、250 个 DDPM 采样步，用 ADM 的 TensorFlow 评估套件；512×512 的 Precision/Recall 用 1000 个真实样本；图 10 用 FID-10K，采样步数 [16, 32, 64, 128, 256, 1000]。
- Gflops 口径：本文核算的公式 $N\,T\,(12d^2+2Td)+6d^2N$（乘加次数，不含 VAE）与表 4 吻合；报告缩放曲线时要同时报告 Gflops、参数量和 token 数。
- 比较 patch size 时要固定模型尺寸，并同时看 token 数和 Gflops；比较不同尺寸时固定 $p$。

## 八、与相关论文的关系

- [Latent Diffusion](../latent_diffusion/论文中文解读.md)：DiT 完全沿用其“冻结 VAE + 在潜空间里做扩散”的框架（也沿用其 VAE，表 2 里的 LDM-4、LDM-8 是对比基线）；唯一的核心改动是把 U-Net 换成 Transformer。LDM 的类条件交叉注意力对应 DiT 里被淘汰的 cross-attention block。
- [DDPM](../ddpm/论文中文解读.md)：DiT 采用与 DDPM 相同的扩散公式、$\mathcal L_{\mathrm{simple}}$、$T=1000$ 与线性 $\beta$ 调度（$1\times10^{-4}$ 到 $2\times10^{-2}$）；DDPM 的 U-Net 是 DiT 要替换的对象。
- [VAE](../vae/论文中文解读.md)：DiT 的潜空间来自 Stable Diffusion 的 VAE（一种 KL 正则的自编码器）。
- [ViT](../vit/论文中文解读.md)：patchify、sine-cosine 位置嵌入以及 S/B/L 的层数、宽度与头数配置都来自 ViT；DiT 的“缩放”思路也借鉴 ViT 的扩展研究。
- [Transformer](../transformer/论文中文解读.md)：DiT block 是对标准 Transformer block 的改造（自注意力、逐位置 MLP，以及可选的交叉注意力）。
- [GAN](../gan/论文中文解读.md)：表 2、表 3 里的 BigGAN-deep 与 StyleGAN-XL 是 GAN 对照；adaLN 的思路来自 GAN 与 ADM 中的自适应归一化。
- [Scaling Laws](../scaling_laws/论文中文解读.md)：本文把“模型计算量越大，指标越好”的语言模型缩放分析（原文引用 Kaplan 等）搬到扩散模型上，但没有拟合幂律。
