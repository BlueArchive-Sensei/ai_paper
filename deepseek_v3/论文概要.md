# 论文概要：《DeepSeek-V3 Technical Report》

## 一、基本信息

- 作者：DeepSeek-AI
- 首次公开：2024-12，arXiv:2412.19437
- 规模：671B 总参数，37B 每 token 激活，128K context
- 训练：14.8T tokens；报告总训练成本 2.788M H800 GPU hours
- 本地材料：[论文 PDF](paper.pdf) · [提取文本](paper.txt) · [中文精读](论文中文解读.md)

## 二、一句话结论

V3 的贡献是把 V2 的 MLA + DeepSeekMoE 扩到 671B，并让算法、训练系统和硬件共同服务于效率：auxiliary-loss-free 负载平衡减少路由损失干扰，MTP 增强表示且可用于 speculative decoding，DualPipe/通信 kernel/FP8 则把 MoE 训练真正跑通。

## 三、关键创新

- **辅助损失无关的负载均衡**：以每 expert bias 动态调整路由，训练时只保留极小的 sequence-wise balance loss。
- **Multi-Token Prediction**：除下一个 token 外，顺序预测多个未来 token；训练后主模型可丢弃额外模块，部署时也可把它用于推测解码。
- **DualPipe**：双向 pipeline 调度，把 forward/backward 与跨节点通信重叠。
- **FP8 混合精度**：细粒度 scaling、累加精度处理和低精度通信共同降低训练成本。
- **硬件共设计**：node-limited routing、定制 all-to-all 与显式硬件建议。

## 四、重要数字

- 256 routed experts + 1 shared expert，每 token 激活 8 routed experts。
- 预训练 2.664M H800 GPU hours，后续阶段约 0.124M，总计 2.788M。
- 论文报告训练过程无不可恢复 loss spike、无 rollback。
- 训练成本表把 GPU 租价假设为 2 美元/小时；“约 5.576M 美元”只是 GPU-hour × 假设单价，不是总项目成本。

## 五、局限

- 训练数据组成、完整训练代码和生产 kernel 未完全公开，成本难以独立复现。
- FP8/DualPipe 收益绑定 H800 拓扑与实现；不能直接外推到任何集群。
- benchmark 数字受提示、采样和模型裁判影响。
- MTP 的训练收益与推测解码收益是两件事，后者依赖 acceptance rate 与 serving 实现。
