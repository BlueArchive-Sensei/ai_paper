# Medusa 论文概要

> **图表阅读约定**：本目录不放论文正文或说明页截图。多头结构、候选树、训练配方和性能表均在中文正文中重建，专有名词保留英文。

## 基本信息

- 题目：*Medusa: Simple LLM Inference Acceleration Framework with Multiple Decoding Heads*
- 作者：Tianle Cai、Yuhong Li、Zhengyang Geng 等
- 时间与会议：2024，ICML 2024
- 主题：multiple decoding heads、tree attention、自推测解码、Medusa-1/2
- 本地资料：[论文 PDF](paper.pdf) · [可检索文本](paper.txt)

## 一句话结论

在目标 LLM 最后一层隐藏状态上增加多个轻量 head，让第 $k$ 个 head 并行预测未来第 $k+1$ 个 token，再把 top candidates 组成树并一次验证，可以避免维护独立 draft model；Medusa-1 冻结 backbone 保持原模型，Medusa-2 联合训练换取更高接受率，论文报告约 2.2× 和 2.3–3.6× 加速。

## 方法组成

- **Medusa heads**：每个 head 是带 residual 的小 MLP + vocabulary projection，分别预测不同未来偏移。
- **Tree attention**：各 head 的 top-$s_k$ 预测做组合，以共享前缀树同时验证。
- **Medusa-1**：冻结原模型，只训练 heads，原 next-token 分布不变，可配标准拒绝采样实现无损加速。
- **Medusa-2**：backbone 与 heads 两阶段联合微调，提高预测一致性；需要专门 recipe 保持原模型能力。
- **Typical acceptance**：放宽精确拒绝条件以提高速度，目标是保持近似质量而非严格同分布。

## 关键证据

- Vicuna-7B：Medusa-1 的 MT-Bench 质量 6.23、加速 2.18×；Medusa-2 质量 6.18、加速 2.83×；baseline 质量 6.17。
- 组件消融：仅 heads 约 1.5×；加 tree attention 约 1.9×；优化树约 2.2×；Medusa-2 约 2.8×。
- 论文整体报告 Medusa-1 超过 2.2×，Medusa-2 为 2.3–3.6×。

## 证据边界

- 主要面向 batch size 1 的个人/交互式场景；高 batch 吞吐结论不同。
- Standard rejection 与 typical acceptance 的质量保证不同，不能把后者称为严格 lossless。
- Medusa-2 修改 backbone；其“质量保持”是基准实证，不是分布等价证明。
- 多头独立预测未来位置，忽略未来 token 间条件依赖，树验证只能纠正而不能消除草稿误差。
