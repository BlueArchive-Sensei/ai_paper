# 论文概要：《MiniMax-M1: Scaling Test-Time Compute Efficiently with Lightning Attention》

## 一、基本信息

- 作者：MiniMax
- 公开时间：2025-06，arXiv:2506.13585
- 基座：MiniMax-Text-01，456B 总参数/45.9B 激活
- 核心贡献：hybrid Lightning Attention 上的长 CoT RL 与 CISPO
- 版本：M1-40k、M1-80k；原生输入 context 1M
- 本地材料：[论文 PDF](paper.pdf) · [提取文本](paper.txt) · [中文精读](论文中文解读.md)

## 二、一句话结论

M1 把线性 attention 的价值从“读很长输入”扩到“便宜地产生很长 reasoning rollout”，并提出 CISPO：不再像 PPO/GRPO 那样把超出 clip 区域的 token gradient 置零，而是只 clip stop-gradient importance weight，保留稀有反思 token 的学习信号。

## 三、训练路线

- 在 Text-01 上继续预训练 7.5T tokens，其中 70% 偏 STEM、代码、书籍与 reasoning。
- 逐步把 context 从 32K 扩到 1M。
- long-CoT SFT 建立 cold start。
- 在数学、代码、逻辑、SWE 环境与开放任务上做 CISPO RL。
- 512 张 H800、约 3 周完成完整 RL；论文按租价估算约 0.53M 美元。

## 四、CISPO

- 采用 GRPO 式组内相对 advantage。
- 对 importance sampling ratio 做 stop-gradient 后裁剪。
- 所有 token 仍保留 `∇ log π` 项，避免罕见但关键的 “Wait/Recheck/Aha” token 在多轮 off-policy update 后被完全 clip 掉。
- 报告在 Qwen2.5-32B 对照中，以一半 steps 达到 DAPO 相近表现。

## 五、局限

- CISPO 的主要受控验证在 32B 基线上；完整 456B run 没有同成本 GRPO/DAPO factorial 对照。
- 论文 SWE-bench 使用可在其基础设施运行的 486 题子集，不是完整 500 题。
- 80K 输出和 1M 输入是上限，不代表每题都应耗尽预算。
- 0.53M 美元同样是 GPU 租价估算，不含数据、人员、预训练和基础设施。
