# 论文概要：《DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning》

## 一、基本信息

- 作者：DeepSeek-AI
- 首次公开：2025-01，arXiv:2501.12948；本地保存的是后续扩展版
- 基座：DeepSeek-V3-Base（671B 总参数、37B 激活）
- 核心主题：可验证奖励上的大规模 RL、cold start、多阶段训练与 reasoning distillation
- 本地材料：[论文 PDF](paper.pdf) · [提取文本](paper.txt) · [中文精读](论文中文解读.md)

## 二、一句话结论

R1 的架构主体并不是新 Transformer，而是用可验证答案奖励 + GRPO 在 V3-Base 上激发长链推理：R1-Zero 证明无 SFT 也会出现反思与延长思考，但可读性差；R1 再用 cold-start SFT、reasoning RL、rejection sampling SFT 和全场景 RL 把能力变成可用模型，并将轨迹蒸馏到小型 dense 模型。

## 三、训练路线

```text
V3-Base
  ├─ 直接 reasoning RL → R1-Zero
  └─ cold-start SFT
       → reasoning-oriented RL
       → rejection sampling + 非推理数据 SFT
       → 全场景 RL
       → DeepSeek-R1
```

## 四、GRPO

GRPO 对同一问题采样一组回答，用组内 reward 标准化估计相对 advantage，不训练单独 critic/value model；再配合重要性比率裁剪与对 reference policy 的 KL 正则更新策略。

## 五、主要发现

- 只有规则奖励的 RL 能显著提升数学/代码推理，并自然出现 self-reflection、verification 与更长 CoT。
- R1-Zero 也出现重复、语言混杂、可读性差等问题，说明能力涌现不等于产品可用。
- cold-start 与多阶段数据改善格式和通用能力。
- 用 R1 轨迹蒸馏到 Qwen/Llama 基座，通常比在同等小模型上直接做大规模 RL 更有效。

## 六、局限

- 训练数据、reward 细节与完整 RL 基础设施未完全公开，权重开放不等于训练可复现。
- 规则奖励适用于有明确答案/测试的任务，对开放写作与事实判断更难。
- benchmark 的采样次数、pass@k/consensus 与输出长度会显著影响 reasoning 模型成绩。
- 长 CoT 可能 reward hack、过度思考、语言混合；可见推理文本也不保证忠实反映内部因果过程。
- 新版论文补充的大量结果不应与首次发布版混用而不标版本。
