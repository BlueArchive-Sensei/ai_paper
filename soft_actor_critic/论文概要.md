# 论文概要：Soft Actor-Critic

> 原文：[Soft Actor-Critic: Off-Policy Maximum Entropy Deep Reinforcement Learning with a Stochastic Actor](https://proceedings.mlr.press/v80/haarnoja18b.html)
>
> 本地材料：[`PDF`](paper.pdf) · [`全文`](paper.txt) · [`详细解读`](论文中文解读.md)

## 0. 一句话主线

SAC 把最大熵目标、off-policy replay 和随机 actor-critic 结合起来，在连续控制中同时追求高回报与高策略熵，以提高样本复用、探索能力和跨随机种子的稳定性。

## 1. 最大熵目标

标准 RL 只最大化回报；SAC 最大化：

$$
J(\pi)=\sum_t\mathbb E_{(s_t,a_t)\sim\rho_\pi}
\left[r(s_t,a_t)+\alpha\mathcal H(\pi(\cdot\mid s_t))\right].
$$

$\alpha$ 控制回报与随机性的权衡。高熵不是无条件随机，而是在保留高价值行为的前提下，对多个近似最优动作保留概率质量。

## 2. 软策略迭代

软 value 为：

$$
V^\pi(s)=\mathbb E_{a\sim\pi}
[Q^\pi(s,a)-\alpha\log\pi(a\mid s)].
$$

软 Bellman backup 为 $Q(s,a)\leftarrow r+\gamma\mathbb E[V(s')]$。策略改进则把策略投影到 $\exp(Q/\alpha)$ 对应的能量分布附近，等价于最小化

$$
\mathbb E_{s\sim D,a\sim\pi_\phi}
[\alpha\log\pi_\phi(a\mid s)-Q_\theta(s,a)].
$$

论文的实用算法使用一个 policy、一个 value/target value，以及两个 Q 网络；双 Q 取较小值以压低过估计。

## 3. 与 PPO/DQN 的位置关系

- 相比 PPO：SAC 是 off-policy，可通过 replay buffer 多次复用旧交互，通常样本效率更高；代价是 bootstrap 与 function approximation 带来更复杂的稳定性问题。
- 相比 DQN：SAC 面向连续动作，无法枚举 $\max_aQ(s,a)$，所以用可微随机 actor 近似策略改进。
- 相比 DDPG/TD3：SAC 学随机策略并显式优化熵，而非依赖确定性 actor 加外部探索噪声。

## 4. 实验结论

论文在 Hopper、Walker2d、HalfCheetah、Ant 与两套 Humanoid 基准上比较 SAC、DDPG、PPO、SQL 和同期 TD3。SAC 在简单任务上相当，在复杂任务上以学习速度和最终分数领先；DDPG 在 Ant/Humanoid 上常无进展。五个 seed 的 Humanoid 对比显示，去掉随机最大熵目标后方差显著增大。

消融还表明：

- 训练用随机策略、评估取 Gaussian mean 往往分数更高；
- 原始 SAC 对 reward scale 很敏感，因为它等价于改变温度；
- target smoothing 太快会不稳，太慢会拖慢学习，论文统一用 $\tau=0.005$。

## 5. 版本边界

本文是 ICML 2018 的原始 SAC：显式包含 value network，并手动调 reward scale。后来更常见的 SAC 版本去掉独立 value network，并自动学习温度 $\alpha$。复现或比较时必须先说明是哪一版。

## 6. 最终判断

SAC 把探索从“给确定性策略额外加噪声”提升为训练目标的一部分，又利用 replay 提高真实交互的使用率。它成为连续控制的核心基线，不是因为最大熵保证任何任务都更好，而是因为随机策略、双 Q、目标网络和 off-policy 更新在复杂控制上形成了一套相对稳定的组合。
