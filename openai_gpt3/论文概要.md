# 论文概要：《Language Models are Few-Shot Learners》

## 一、基本信息

- 作者：Tom B. Brown 等，OpenAI
- 公开时间：2020-05，arXiv:2005.14165
- 模型：GPT-3，最大 175B 参数、2048 token context
- 核心主题：规模化自回归预训练与 in-context learning
- 开放边界：论文公开，GPT-3 权重与训练数据未开源
- 本地材料：[论文 PDF](paper.pdf) · [提取文本](paper.txt) · [中文精读](论文中文解读.md)

## 二、一句话结论

GPT-3 的关键发现是，模型规模扩大后可以仅凭 prompt 中的指令和示例完成许多新任务，不更新参数；但 few-shot 并非真正训练，能力随任务波动明显，并伴随数据污染、偏见、事实错误和巨大训练成本。

## 三、方法

- 训练 8 个从 125M 到 175B 的 decoder-only Transformer。
- 比较 zero-shot、one-shot、few-shot，不对下游任务做梯度更新。
- 数据混合来自过滤 Common Crawl、WebText2、Books 与 Wikipedia，并按质量重采样。
- 最大模型使用交替 dense/local banded sparse attention。

## 四、主要贡献

- 把 in-context learning 作为大模型通用任务接口系统评估。
- 展示能力随参数/计算规模总体平滑上升，但某些任务存在明显阈值。
- 对 benchmark contamination 做专门分析。
- 用较长篇幅讨论生成滥用、偏见、能耗和不可控性。

## 五、局限

- GPT-3 仍会在逻辑、一致性和事实性上失败；双向理解任务也不总占优。
- 2048 context 限制 few-shot 示例数量。
- 公开网页数据使 contamination 难以完全排除。
- 模型和数据未开放，外部只能验证输出，不能完整复现训练。
- 175B 的成功不能证明单纯扩大规模可解决对齐和可靠性。
