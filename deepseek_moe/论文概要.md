# 论文概要：《DeepSeekMoE: Towards Ultimate Expert Specialization in Mixture-of-Experts Language Models》

## 一、基本信息

- 作者：Damai Dai、Chengqi Deng、Chenggang Zhao 等，DeepSeek-AI
- 公开时间：2024-01，arXiv:2401.06066
- 核心主题：细粒度专家分割与 shared expert isolation
- 本地材料：[论文 PDF](paper.pdf) · [提取文本](paper.txt) · [中文精读](论文中文解读.md)

## 二、一句话结论

DeepSeekMoE 不只是“多放一些专家”，而是把同等 FFN 参数切成更多、更小的 routed experts，让每个 token 组合更多细粒度专家，同时抽出 shared experts 承担公共知识；这样既增加组合空间，又减少 routed experts 的知识冗余，后来成为 DeepSeek-V2/V3 的 MoE 基础。

## 三、两项关键设计

1. **Fine-grained expert segmentation**：把原来的每个 expert 切成 `m` 个小 expert，并把 top-k 扩为 top-`mk`，保持激活参数量近似不变，但组合更灵活。
2. **Shared expert isolation**：固定激活少量 shared experts，承接所有 token 的公共知识，让 routed experts 更专门化。

## 四、主要证据

- DeepSeekMoE 2B 与更大 GShard 基线比较，在更少 expert 参数/计算下取得相当表现。
- 16B 模型以约 40% 的计算量达到与 LLaMA2 7B 相当的总体表现。
- 145B 预实验继续显示对 GShard 的优势，并以少得多的激活计算接近 DeepSeek 67B。
- 消融显示，细粒度分割与 shared expert 各自有贡献；关闭一部分 routed experts 时，细粒度专家表现出更强替代性。

## 五、局限

- “专家更专门化”主要由下游表现和禁用专家实验间接支持，没有给出完整、可解释的知识分工证明。
- MoE 总 FLOPs 低不代表训练/推理端到端成本同比下降，all-to-all、路由、padding 和负载不均仍可能占主导。
- 大规模 145B 结果属于初步验证，训练 token 与现代 V3 级规模相差很大。
- shared experts、专家粒度和 top-k 的最优点与硬件网络强相关。
