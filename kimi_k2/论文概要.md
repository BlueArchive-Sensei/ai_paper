# 论文概要：《Kimi K2: Open Agentic Intelligence》

## 一、基本信息

- 作者：Kimi Team（月之暗面 / Moonshot AI）
- 公开时间：2025-07，arXiv:2507.20534
- 模型：1.04T 总参数，32.6B 每 token 激活，128K context
- 核心贡献：超稀疏 MoE、MLA、MuonClip、agentic data synthesis 与统一 RL
- 开放边界：Base/Instruct 权重开放，使用 Modified MIT License
- 本地材料：[论文 PDF](paper.pdf) · [提取文本](paper.txt) · [中文精读](论文中文解读.md)

## 二、一句话结论

Kimi K2 沿 DeepSeek-V3 式 MLA + MoE 扩到 1T，但把 experts 增到 384、attention heads 减到 64，并用 MuonClip 解决 Muon 在大规模训练中的 attention-logit 爆炸；其 Instruct 模型重点是非长思考的 agent/tool-use，而不是 k1.5 式 long-CoT。

## 三、架构

- 61 层，hidden size 7168。
- 384 routed experts，top-8，另有 1 shared expert；sparsity 48。
- 32.6B 激活参数，64 attention heads，MLA。
- 1 个 dense layer，128K context。
- 相比 DeepSeek-V3，以更多专家提高容量，以更少 attention heads 降低长 context inference FLOPs。

## 四、MuonClip

- Muon 对 2D hidden weights 做矩阵正交化式更新，token efficiency 较好。
- 大规模时 Q/K 权重可能导致 attention logits 爆炸。
- QK-Clip 在 optimizer step 后按每 head 的最大 logit 缩放 query/key projection weights，将其限制在阈值内。
- K2 报告在 15.5T tokens 训练中没有 loss spike。

## 五、agentic 后训练

- 合成真实/模拟工具、任务与轨迹。
- 对可验证任务使用 RLVR；开放任务用 self-critique rubric reward。
- K2-Instruct 的主要报告口径是 non-thinking agentic model，不能与无限长 CoT 模型直接按分数比较。

## 六、局限

- 1T total 权重部署成本极高，32B active 不等于 32B 模型的存储/通信。
- MuonClip 的稳定性证据主要来自 K2 自身训练和较小消融，跨架构泛化仍需验证。
- 自生成/改写数据可能放大教师错误，fidelity filter 不是事实保证。
- agent benchmark 强依赖 scaffold、工具集、timeout 与执行环境。
- Modified MIT 不是标准 MIT，部署应阅读附加条款。
