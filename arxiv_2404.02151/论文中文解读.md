# 论文中文解读：简单自适应攻击为何足以越狱主流模型

> 原文：[Jailbreaking Leading Safety-Aligned LLMs with Simple Adaptive Attacks](https://arxiv.org/abs/2404.02151)
>
> 作者：Maksym Andriushchenko、Francesco Croce、Nicolas Flammarion（EPFL）
>
> 发表：ICLR 2025

本地材料：[`PDF`](paper.pdf) · [`提取文本`](paper.txt)

## 0. 一句话主线

很多防御只是对既有攻击有效；一旦攻击者利用目标模型的概率、API 接口或已知结构做有针对性的小规模搜索，看似坚固的安全对齐仍可快速失效。

## 1. 什么叫自适应攻击

它不是把同一个 jailbreak 提示复制到所有模型，而是根据目标的可观测信息和接口特性调整攻击：

- 可读 log probabilities 时，优化后缀，使模型更可能以表示顺从的 token 开头。
- 不能读 logprobs 时，从其他模型迁移已找到的字符串或利用 API prefilling。
- 对已知对特定上下文学习形式敏感的防御，专门改造提示模板。

## 2. 随机搜索为什么有效

攻击从一个大致有效的对抗模板出发，随机替换后缀 token，保留能提高目标 token 概率的变体，多次重启以避免局部最优。这不需要复杂梯度攻击，但它不是“完全无信息”：成功依赖好的初始模板、合适的目标和对目标模型的适配。

## 3. 论文报告的结果

在作者使用的 50 条 AdvBench 有害请求和 GPT-4 评审设置下，攻击对多个开源模型、GPT-3.5、GPT-4o 以及专门针对 GCG 训练的 R2D2 报告 100% 成功率；作者也通过迁移或 prefilling 对当时 Claude 型号报告 100% 成功率。

论文还把受限 token 集上的随机搜索用于中毒模型的木马触发字符串发现，说明 jailbreak 与后门触发搜索在优化形式上有共性。

## 4. 为什么 100% 不能脱离评估设置

- 成功由 GPT-4 judge 判定，自动评审可能把形式上顺从、实际上无用的输出判成成功。
- 仅使用 50 条筛选请求，不代表所有危险类型、语言和产品层防御。
- 许多模型和 API 已更新，prefilling 等接口也可被产品方限制。
- 攻击能力应与查询成本、重启数量、可用信息和人工先验一起报告。

这正是后来 StrongREJECT 等工作强调“空越狱”和高质量人类一致评估的原因。

## 5. 对防御研究的意义

一个防御不能只对固定的公开攻击集报告低 ASR，而应接受知道防御细节的自适应对手测试。否则测到的可能只是攻击者没有重新调参。

工程上还应谨慎暴露 logprobs、可控 prefilling 和其他能直接为攻击优化提供反馈的接口；但封闭接口只是增加成本，不是对安全对齐本身的替代。

## 6. 最终评价

本文不是说“任何人用一条提示就能 100% 攻破任何模型”，而是证明安全声称必须在自适应威胁模型下成立。其主要遗产是评估原则：防御要和会学习、会调整的攻击者比，不是和静态题库比。
