# EAGLE 论文概要

## 基本信息

- 题目：*EAGLE: Speculative Sampling Requires Rethinking Feature Uncertainty*
- 作者：Yuhui Li、Fangyun Wei、Chao Zhang、Hongyang Zhang
- 时间与会议：2024，ICML 2024
- 主题：feature-level autoregression、token-shift、tree attention、lossless speculative sampling
- 本地资料：[论文 PDF](paper.pdf) · [可检索文本](paper.txt)

## 一句话结论

未来 token 很离散，直接预测困难；EAGLE 改为用轻量 autoregression head 预测 target 倒数第二层 feature，再由原 LM head 转成 token，并把前移一位的已采样 token 一同输入以消除 feature 的一对多不确定性。论文在 Vicuna/LLaMA2-Chat 上报告约 2.7–3.5 倍延迟加速且保持目标分布。

## 关键创新

1. **Feature-level drafting**：连续高层 feature 比离散 token 序列更容易外推。
2. **Shifted token conditioning**：同一 feature 可对应随机采样的多个 token；把实际采样 token 向前移动一位输入下一步，恢复必要条件信息。
3. **轻量 AR head**：复用 target feature，不运行独立完整 draft model。
4. **Tree draft + exact verification**：多候选树并行验证，用标准采样校正保持 target distribution。

## 关键证据

- Vicuna/LLaMA2-Chat 多任务、温度 0 下常见加速约 2.8–3.8×，每次 target forward 平均产生约 3.6–4.5 token。
- LLaMA2-Chat 70B 在论文摘要中为 2.7–3.5×，吞吐约翻倍。
- Tree attention 相比链式草稿使平均接受长度增加约 0.6–0.8，速度增加约 0.3–0.5×。
- 特征 + shifted token 的输入消融带来最大改善，支持“采样随机性必须显式条件化”的论点。
- Mixtral 8x7B 只达 1.5×，说明 MoE 验证多个 token 会激活更多 experts，硬件收益更难。

## 边界

- 需要训练每个 target 对应的 EAGLE head，不是完全 training-free。
- 主指标偏 latency、batch 1；吞吐和大 batch 的收益更小。
- “lossless”来自最终 target 验证/校正，不代表 feature prediction 无误。
- 速度比强烈依赖 kernel、量化、任务模板和接受树配置。
