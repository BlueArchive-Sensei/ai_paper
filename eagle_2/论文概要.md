# EAGLE-2 论文概要

## 基本信息

- 题目：*EAGLE-2: Faster Inference of Language Models with Dynamic Draft Trees*
- 作者：Yuhui Li、Fangyun Wei、Chao Zhang、Hongyang Zhang
- 时间与会议：2024，EMNLP 2024
- 主题：dynamic draft tree、context-aware speculation、confidence calibration、lossless acceleration
- 本地资料：[论文 PDF](paper.pdf) · [可检索文本](paper.txt)

## 一句话结论

EAGLE/Medusa 的固定树假设“同一位置总值得分配相同节点数”，但真实接受率强烈依赖上下文。EAGLE-2 利用 EAGLE draft 置信度与 target 接受率的校准关系，先扩展高价值节点、再全局重排选出固定预算的动态树，无需重新训练即可把平均加速提高到约 3.05–4.26×，并保持目标分布。

## 算法要点

- **Expansion**：维护 frontier，反复扩展价值最高的节点。
- **Value**：节点自身 confidence 与祖先 confidence 的乘积，近似整条前缀被接受的联合概率。
- **Reranking**：扩展后对所有候选按 value 全局排序，选固定数量节点形成最终树。
- **Verification**：沿用 EAGLE 的 tree attention 与 exact acceptance，所以动态构树只改变候选覆盖，不改变 target distribution。

## 核心证据

- Vicuna/LLaMA2-Chat、六任务上，论文版本报告 3.05–4.26×，比 EAGLE 快约 20%–40%；正式 EMNLP 页面总结最高约 5×、约为 EAGLE 的 1.3×。
- Vicuna-13B 温度 0 的六任务平均：EAGLE 2.95×、$\tau=3.82$；EAGLE-2 4.04×、$\tau=4.65$。
- LLaMA2-Chat 70B MT-Bench：EAGLE 3.01×，EAGLE-2 3.51×。
- 消融中，去掉 value 与 reranking 为 2.81×；完整方法 3.62×，证明两个阶段均贡献。

## 边界

- 动态树依赖 confidence 校准；域外、量化或换 target 后校准偏移会降低节点分配质量。
- $\tau$ 只表示接受长度，不含 draft/排序/kernel 开销；speedup 仍依赖硬件。
- 论文比较集中在 batch 1 与指定模型；高并发吞吐需重新选节点预算。
- QA/摘要域接受长度较低，作者归因于 draft 训练数据中预训练知识和摘要样本不足。
