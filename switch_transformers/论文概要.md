# Switch Transformer 论文概要

## 基本信息

- 题目：*Switch Transformers: Scaling to Trillion Parameter Models with Simple and Efficient Sparsity*
- 作者：William Fedus、Barret Zoph、Noam Shazeer
- 期刊：JMLR 23(120)，2022
- 原文：https://www.jmlr.org/papers/v23/21-0998.html
- 主题：top-1 MoE、capacity factor、稳定训练、专家并行

## 一句话结论

Switch Transformer 把每个 token 从 top-(k) experts 简化为 top-1 expert，用固定 expert capacity、单一负载均衡损失、router FP32 和缩小初始化等工程组合，使稀疏 Transformer 能以 bfloat16 稳定扩展到万亿参数。

## 核心设计

- 用 Switch FFN 替换 Transformer 中的 dense FFN。
- router 为每个 token 选概率最高的一个 expert。
- 每 expert capacity：

$$
C=\frac{tokens\ per\ batch}{N_{experts}}\times capacity\ factor.
$$

- 超过 capacity 的 token 跳过 expert，经 residual path 继续。
- 辅助损失同时约束实际 token fraction (f_i) 与平均 router probability (P_i)：

$$
L_{aux}=\alpha N\sum_i f_iP_i.
$$

## 主要结果

- FLOP-matched Switch-Base/Large 相对 dense T5 展示更快的预训练质量提升，论文摘要报告同资源下最高约 7×。
- 低精度训练通过 router selective precision 等手段稳定。
- 最终训练 395B 与 1.6T 参数模型；相对 T5-XXL 报告约 4× speedup。
- 在多种下游任务和 101 种语言上多数优于相应 dense baseline。

## 局限

- top-1 简化通信，但更依赖容量与负载均衡，overflow token 会被丢弃。
- parameter count 不是 inference cost；1.6T 模型仍有巨大的权重存储和分布式通信。
- 多数大规模结果来自 TPU 与特定 Mesh TensorFlow 映射。
- 论文中的 speedup 有“按 step、按 wall-clock、达到某质量”多种口径，不能混用。

## 阅读价值

这篇是理解现代 Transformer MoE 的最佳入口之一：算法简单，但 capacity、token dropping、router precision、初始化、expert dropout 和并行映射共同决定是否可训练。
