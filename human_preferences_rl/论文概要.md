# 论文概要：Deep Reinforcement Learning from Human Preferences

> 原文：[Deep Reinforcement Learning from Human Preferences](https://proceedings.neurips.cc/paper/2017/hash/d5e2c0adad503c91f91df240d0cd4e49-Abstract.html)
>
> 本地材料：[`PDF`](paper.pdf) · [`全文`](paper.txt) · [`详细解读`](论文中文解读.md)

## 0. 一句话主线

论文把难写的奖励函数转成少量“两个短轨迹片段哪个更好”的人类比较，用监督学习拟合 reward model，再让普通 RL 优化预测奖励；人类反馈只覆盖不到 1% 的环境交互，却能学习 Atari、模拟机器人和后空翻等目标。

## 1. 三个异步循环

1. policy 与环境交互，并以当前预测奖励 $\hat r$ 做 RL；
2. 从新轨迹中选两段 1–2 秒 clips，请人类偏好、判平或跳过；
3. reward ensemble 用累计 clip reward 预测偏好，并用全部比较持续更新。

偏好模型采用 Bradley–Terry 形式：

$$
P(\sigma^1\succ\sigma^2)=
\frac{\exp\sum_t\hat r(s_t^1,a_t^1)}
{\exp\sum_t\hat r(s_t^1,a_t^1)+
 \exp\sum_t\hat r(s_t^2,a_t^2)}.
$$

policy 端在 Atari 用 A2C，在 MuJoCo 用 TRPO；reward model 输出会做零均值、固定标准差归一化。

## 2. 主结果

- 8 个 MuJoCo 任务上，700 个人类比较通常接近真实 reward RL；1400 个合成偏好有时略超真 reward，可能来自更好的 reward shaping。
- 7 个 Atari 游戏上，5500 个人类比较取得实质学习，但更难匹配真实 reward；Q*bert 的短 clips 难判断，Enduro 中人类能奖励“正在超车”的进展，反而提供更好 shaping。
- 新行为：Hopper 连续后空翻用 900 queries、不到一小时；Half-Cheetah 单腿前进用 800；Enduro 与其他车辆并行约 1300。
- 消融显示只在开头静态采集偏好会产生 reward hacking 式异常行为；在线交错反馈、较长片段和正则化通常重要。

## 3. 为什么 pairwise preferences 有用

人类不必演示动作，也不用给不同阶段一致的绝对分数，只需比较两个短片段。比较信号对奖励的平移和尺度不敏感，降低标注难度；reward model 又把几千次人类判断扩展为数百万环境步的密集预测奖励。

## 4. 局限

- 学到的是“标注者在所见 clips 上的偏好预测器”，不是完整人类价值函数。
- policy 会主动寻找 reward model 漏洞；静态数据尤其容易被分布外行为利用。
- 主实验中真实人类反馈常只有单次运行，方差和标注者差异估计不足。
- 合成 oracle 偏好来自真实 reward，不代表真实人类噪声。
- 1–2 秒局部比较难表达长程后果、不可见状态、规则遵守和低概率风险。

## 5. 最终判断

这篇论文给出了现代 RLHF 的基本闭环：偏好数据 → reward model → RL → 新数据与新偏好。真正的贡献不只是减少标注量，而是认识到 reward model 必须与策略共同演化；否则优化器会把预测误差变成行为。它证明了可行性，也提前展示了 reward hacking、分布偏移与监督带宽的核心问题。
