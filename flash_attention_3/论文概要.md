# 论文概要：《FlashAttention-3: Fast and Accurate Attention with Asynchrony and Low-precision》

## 基本信息

- 时间：2024
- 原文：[官方论文/页面](https://arxiv.org/abs/2407.08608)
- 本地：[PDF](paper.pdf) · [可检索文本](paper.txt) · [中文精读](论文中文解读.md)

## 一句话结论

FA3 针对 Hopper 的 TMA、WGMMA 和异步执行重写 attention pipeline，并加入更准确的 FP8 路径。

## 核心方法

warp specialization 把 producer（TMA 搬运）与 consumer（WGMMA 矩阵乘 + softmax）分工，反向另加 dQ writer；两个 consumer warpgroup 之间做 pingpong、warpgroup 内做 2-stage GEMM–softmax 流水，隐藏数据搬运和非 matmul（softmax）延迟。FP8 前向使用 block quantization 与 incoherent processing 降低误差。

## 历史影响

它标志高性能 attention 从通用 CUDA 优化进入“算法与特定 GPU 指令流水协同设计”阶段。

## 局限

主要面向 H100（Hopper）；A100 或其他加速器不能直接获得同样收益。FP8 只有前向，精度结论只在带离群值的合成数据上验证；反向只测了非因果 head 维度 64/128。

## 阅读衔接

FA4 延续协同设计，但 Blackwell 的 tensor core 增长快于 shared memory/SFU，瓶颈再次迁移。
