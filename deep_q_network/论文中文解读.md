## 0. 先把论文放回 2015 年

今天看“像素进、动作价值出”的卷积网络很自然，但论文面对的是一个当时反复失败的组合：Q-learning 的 bootstrap 目标本来就会随网络变化，策略又决定后续数据分布，相邻视频帧还高度相关；把三者直接交给非线性神经网络，很容易振荡甚至发散。

DQN 的突破因此不只是加深网络，而是同时处理三种耦合：

1. **表示学习**：从原始像素中学出对控制有用的特征；
2. **数据分布**：用 replay memory 打散轨迹相关性并复用旧数据；
3. **学习目标**：用延迟目标网络减慢 bootstrap target 的漂移。

## 1. 从 Bellman 最优方程到 DQN 损失

最优动作价值函数满足：

$$
Q^*(s,a)=\mathbb E\left[r+\gamma\max_{a'}Q^*(s',a')\mid s,a\right].
$$

DQN 用网络 $Q(s,a;\theta)$ 近似 $Q^*$。若直接让同一个网络既给预测又给目标，参数的一次更新会同时改变等式两边。论文改用旧参数 $\theta^-$ 生成目标：

$$
y=r+\gamma\max_{a'}Q(s',a';\theta^-),
$$

$$
L(\theta)=\mathbb E_{(s,a,r,s')\sim U(D)}[(y-Q(s,a;\theta))^2].
$$

终止状态的目标只有 $r$。网络对当前状态一次输出所有动作的 Q 值，行为端选择 $\arg\max_aQ(s,a)$，训练时保留少量随机动作作探索。

这里有两个常见误读：

- target network 不是第二个独立学习的 critic，而是在线 Q 网络的延迟副本；
- experience replay 不会消除 off-policy 偏差，而是因为 Q-learning 本身可 off-policy，才允许对旧行为产生的数据反复学习。

## 2. 输入、网络与训练循环

原始 Atari 画面为 $210\times160$ 彩色图像、60 Hz。预处理把图像转成 $84\times84$ 灰度帧，并堆叠最近 4 帧，使网络能推断速度和方向。网络由三层卷积、一个 512 单元全连接层和动作输出层构成；不同游戏合法动作数不同，但主体结构和超参数相同。

完整循环是：

1. 用当前 $\epsilon$-greedy 策略执行动作；
2. 把 $(s_t,a_t,r_t,s_{t+1})$ 写入固定容量 replay memory；
3. 均匀抽取 minibatch，计算固定目标网络给出的 TD target；
4. 更新在线网络；
5. 每隔 $C$ 步把在线参数复制给目标网络。

经验回放同时带来三项收益：一条转移可被多次使用；随机采样减少相邻样本相关性；训练分布由许多旧策略混合而成，减弱“刚把左移估高—随后数据全来自左侧—进一步强化左移”的反馈环。局限也被作者直接指出：均匀回放不区分重要转移，有限缓冲区会覆盖旧经验，这后来促成 prioritized replay 等工作。

## 3. 训练曲线证明了什么

Figure 2 在 Space Invaders 和 Seaquest 上同时画 episode score 与固定状态集的平均预测 Q 值。分数本身噪声很大，而 held-out 状态上的 Q 估计更平滑地上升，说明网络不是只记住最近一段轨迹。

但这张图不能证明 Q 值校准正确：论文对奖励做了 $[-1,1]$ 裁剪，纵轴不再对应原始游戏分数；bootstrap 估计也可能整体偏高。它能支持的较弱结论是训练没有明显发散，且价值估计与行为改善大致同向。

## 4. Figure 3：49 游戏结果要逐游戏读

归一化公式是：

$$
100\times\frac{S_{\text{DQN}}-S_{\text{random}}}
{S_{\text{human}}-S_{\text{random}}}.
$$

论文报告 DQN 在 43 个游戏上超过当时最佳 RL 方法，并在 29 个游戏上超过 75% 人类归一化分数。真正值得注意的是分布，而非单个平均值：

- Video Pinball、Boxing、Breakout 等明显超过人类测试者；
- Seaquest、Ms. Pac-Man、Frostbite 等仍远低于人类；
- Montezuma's Revenge、Private Eye 等几乎不学习。

后一组任务需要长时间无奖励探索、记住钥匙/房间状态或执行多阶段计划。DQN 的 $\epsilon$-greedy 随机探索很难偶然触达奖励；这说明“能稳定拟合像素价值函数”不等于“能发现稀疏奖励策略”。

另一个统计陷阱是某些游戏的分母很小或机器分数极大，人类归一化百分比会非常夸张。跨游戏比较应看中位数和逐游戏分布，不能让 Video Pinball 一类极端值支配结论。

## 5. 表示分析：价值相关，不等于语义可解释

Figure 4 对最后隐层做 t-SNE。视觉相似的状态往往聚在一起；更有意思的是，部分像素差异较大的屏幕也会因预期价值相近而接近。这与“表示受控制目标而非纯重建目标塑形”的解释一致。

然而 t-SNE 是非线性二维投影，会扭曲全局距离；颜色又直接取自同一网络预测的价值。它不能单独证明网络形成了可迁移对象、规则或因果状态变量。论文额外把人类与 DQN 轨迹的隐表示一起投影，发现部分结构重叠，最多说明网络对另一行为策略访问的状态也能给出相似编码。

## 6. Breakout 策略与长时程失败

DQN 在 Breakout 中学会从侧面打洞，让球进入砖墙后方连续得分。这是从像素和分数自发出现的延迟策略，说明卷积价值函数能够利用若干秒跨度的后果。

但论文紧接着承认，更长时程规划仍是主要困难，Montezuma's Revenge 是典型反例。因此 Breakout 不应被泛化为“DQN 已具有规划能力”；它更像在密集反馈和相对短 horizon 下，bootstrapped value 传播出了一个有效技巧。

## 7. Methods：容易影响复现的细节

除两项著名机制外，复现还依赖一组常被省略的工程选择：

- action repeat/frame skip 让同一动作持续多帧，并在相邻帧间做最大池化以处理 Atari 闪烁；
- 奖励被裁剪到符号范围，使同一学习率可跨游戏使用，但牺牲奖励幅度；
- TD error 在 $[-1,1]$ 内用平方损失、区间外近似绝对值损失，即后来常说的 Huber 风格裁剪；
- replay memory 只保留最近 $N$ 条转移，并在积累一定经验后开始更新；
- 训练策略的 $\epsilon$ 退火与评测时的 $\epsilon=0.05$ 不同；
- 每个游戏独立训练，参数并不跨游戏共享。

这些设置共同构成 DQN；只实现一个卷积 Q 网络并不等于复现论文。

## 8. Extended Data Table 3：消融应怎样解释

Extended Data Table 3 在 5 个验证游戏、3 个学习率下组合开关 replay 与 target network。整体趋势支持两者都有帮助，完整 DQN 最稳；但它不是大规模因果分解：

- 只训练 10M frames，而主结果为 50M；
- 游戏仅是用于开发超参数的 5 个验证环境；
- 报告各训练过程中的最高验证分，存在选择最好 checkpoint 的乐观性；
- 学习率与机制存在交互，不能把单个格子的差异当作普遍效应量。

Extended Data Table 4 再将深卷积网络替换为线性逼近器，结果明显下降，支持端到端层级表示对视觉控制的重要性。

## 9. “通用算法”的准确含义

论文所称 generality 是：

- 同一输入接口（屏幕、分数）；
- 同一算法、网络模板和大多数超参数；
- 面对 49 个不同游戏都能训练。

它不意味着：

- 一个模型同时玩 49 个游戏；
- 在游戏之间迁移知识；
- 不知道游戏边界、动作集合或 episode 终止；
- 对新游戏 zero-shot 泛化。

这个区分正好为本仓库后面的 Policy Distillation 和 Distral 铺路：前者把多个已学策略压到一个网络，后者让共享蒸馏策略在学习过程中反向指导各任务。

## 10. 论文之后仍成立与已经过时的部分

仍然成立的思想：

1. replay buffer 是提高 off-policy 数据复用率和减弱相关性的核心工具；
2. delayed/target estimates 是控制 bootstrap 反馈回路的通用办法；
3. 深度 RL 结果必须跨随机种子、逐环境报告；
4. 探索失败不能靠更准确地拟合已有数据自动解决。

已经需要历史化理解的部分：

- 原始 DQN 会产生 maximization bias，后来 Double DQN 将选动作与评动作分开；
- 均匀回放被 prioritized replay 等方法扩展；
- 单点期望 Q 被 distributional RL 扩展为回报分布；
- sticky actions、human starts 和更严格统计协议揭示了确定性模拟器评测的脆弱性。

## 11. 最终结论

DQN 的核心贡献是把一个本来相互追逐、容易发散的学习系统拆出两个时间尺度：replay memory 让数据分布变化更慢，target network 让监督目标变化更慢。卷积网络于是能在这两个缓冲器之间，从像素中学出价值相关表示。

论文最强的正面证据是跨 49 个视觉任务的统一训练配方，最重要的负面证据则是稀疏奖励与长时程任务上的系统失败。它奠定了深度价值学习的工程基础，却没有解决探索、规划、迁移或真实世界数据效率。
