# 资料概要：《MLIR: A Compiler Infrastructure for the End of Moore's Law》

## 基本信息

- 时间：2020（arXiv v2，2020 年 3 月）
- 来源：[论文/官方页面](https://arxiv.org/abs/2002.11054)
- 本地：[PDF](paper.pdf) · [可检索文本](paper.txt) · [中文精读](论文中文解读.md)

## 一句话结论

MLIR 提供可扩展 dialect、operation/type/attribute 与 progressive lowering 基础设施，让不同领域和硬件在同一 SSA 框架中保留合适抽象层。

## 核心设计

dialect 是带命名空间的 Op/type/attribute 分组（语义由其中的 Op 定义），可逐级转换，不必过早降到 LLVM IR；regions/blocks 支持控制流和嵌套结构，traits/interfaces 让通用 pass 复用到不同 dialect。MLIR 本身不是一个完整 AI compiler，而是构建编译器的基础设施，论文里的应用有 TensorFlow 图、affine（多面体）代码生成、Fortran 前端 FIR 和领域专用编译器。

## 历史位置

它缓解“每个加速器重造前端×后端组合”的碎片化问题，使多级 IR 和可组合 pass 成为现代 AI 编译器主流。

## 局限

可扩展也会导致 dialect 碎片、conversion 边界和 pass ordering 复杂；采用 MLIR 不自动获得高性能，仍需领域成本模型、runtime 与 kernel。

## 阅读衔接

Glow 展示手工双层 IR，MLIR 把这一思想基础设施化；IREE、XLA Runtime 和多个 kernel DSL 建在其上。
