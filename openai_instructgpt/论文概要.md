# 论文概要：《Training Language Models to Follow Instructions with Human Feedback》

## 一、基本信息

- 作者：Long Ouyang 等，OpenAI
- 公开时间：2022-03，arXiv:2203.02155
- 模型：InstructGPT，1.3B / 6B / 175B
- 核心方法：SFT → reward model → PPO，外加 pretraining mix（PPO-ptx）
- 开放边界：论文公开，模型权重/完整偏好数据未开放
- 本地材料：[论文 PDF](paper.pdf) · [提取文本](paper.txt) · [中文精读](论文中文解读.md)

## 二、一句话结论

InstructGPT 建立了现代 RLHF 三阶段范式：先模仿示范，再从成对偏好训练 reward model，最后用 PPO 优化策略；1.3B InstructGPT 的输出可被标注者偏好于 175B GPT-3，但这衡量的是特定用户/标注者分布下的意图遵循，不等于普遍价值对齐。

## 三、三阶段

1. 收集人类 demonstrations，监督微调 GPT-3 得到 SFT。
2. 对同一 prompt 的多份输出做排序，训练 reward model。
3. 用 PPO 最大化 reward，并以 KL penalty 限制策略偏离 SFT；PPO-ptx 混入预训练 loss 以减少能力回退。

## 四、主要证据

- API prompt 上，人评明显偏好 InstructGPT。
- 1.3B PPO-ptx 可胜过原始 175B GPT-3，说明“对齐目标”与“参数规模”不是一回事。
- TruthfulQA、毒性与幻觉指标总体改善。
- 在公开 NLP benchmark 上存在 alignment tax，混入 pretraining gradients 可缓解。

## 五、局限

- reward model 会继承标注者、准则与采样分布偏差。
- PPO 可利用 reward model 漏洞，KL 只能约束距离，不能保证目标正确。
- 标注者主要是英语、特定文化和教育背景，不能代表所有用户。
- Helpful、Honest、Harmless 之间会冲突；论文没有给出普适聚合规则。
