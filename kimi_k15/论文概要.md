# 论文概要：《Kimi k1.5: Scaling Reinforcement Learning with LLMs》

## 一、基本信息

- 作者：Kimi Team（月之暗面 / Moonshot AI）
- 首次公开：2025-01，arXiv:2501.12599
- 类型：多模态 reasoning 模型技术报告
- 核心贡献：128K long-CoT RL、online mirror descent 变体、partial rollout 与 long2short
- 开放边界：报告公开；官方仓库未发布 k1.5 完整模型权重/训练代码
- 本地材料：[论文 PDF](paper.pdf) · [提取文本](paper.txt) · [中文精读](论文中文解读.md)

## 二、一句话结论

k1.5 把 context length 当作 RL scaling 轴：用最终答案 reward 学习长达 128K 的试错/反思轨迹，以 online mirror descent 变体更新 policy，并通过 partial rollout 跨 iteration 复用长回答前缀；它说明不依赖 MCTS、value model 或 process reward 也能获得强推理，但架构/数据披露和外部复现仍有限。

## 三、算法与系统

- 对同一问题采样多份回答，以规则 verifier 或 reward model 判断最终答案。
- 每轮把当前 policy 作为 reference，优化 reward 与相对熵正则的 mirror-descent 目标。
- 不训练 value network，鼓励错误路径后自我恢复，而非逐步惩罚。
- partial rollout 将超长轨迹切成片段；旧前缀从 replay buffer 复用，只继续生成尾部。
- length reward、curriculum/prioritized sampling 抑制无效 overthinking。

## 四、主要结果

报告给出 long-CoT 在 AIME、MATH-500、Codeforces、MathVista 等接近 o1 的结果；long2short 再通过 model merging、shortest rejection sampling、DPO 等把部分能力压回短回答。

## 五、局限

- 与闭源模型比较的采样预算、prompt 与工具未必完全一致。
- 最终答案 reward 无法判断中间 CoT 是否忠实或逻辑严谨。
- partial rollout 使用旧 policy 生成的前缀，带来 off-policy/staleness，需要算法与实现控制。
- 128K 是最大 RL context，不表示所有输出都应如此长。
- 权重/训练栈未完整开放，报告公开不等于模型开源。
