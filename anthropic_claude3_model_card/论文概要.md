# 资料概要：《The Claude 3 Model Family: Opus, Sonnet, Haiku》

## 一、基本信息

- 发布方：Anthropic
- 公开时间：2024-03
- 类型：模型卡；本地官方 PDF 还收录后续 Claude 3.x 更新附录
- 对象：Claude 3 Opus、Sonnet、Haiku
- 开放边界：公开能力/安全评测与高层训练方法，不公开参数量、具体架构、权重或训练代码
- 本地材料：[官方 PDF](paper.pdf) · [提取文本](paper.txt) · [中文精读](论文中文解读.md)

## 二、一句话结论

Claude 3 模型卡说明 Anthropic 如何用 Constitutional AI、RLHF、能力评测和 Responsible Scaling Policy 发布一族速度/能力不同的多模态模型；它并没有公开 Claude 的内部层数、attention 或参数规模，因此不能当作 Claude Code 的架构论文。

## 三、公开内容

- 三档模型的推理、代码、视觉、长上下文与多语言评测。
- Constitutional AI 与人类反馈的高层训练描述。
- 错误拒绝、事实准确性、长上下文 recall 与人类偏好。
- 生物、网络、自治等 catastrophic-risk evaluation 和 ASL-2 发布判断。
- 多模态红队、偏见、选举完整性与社会影响评估。

## 四、关键边界

- Claude 3 支持图像输入，但模型卡不披露视觉 encoder/connector。
- 长上下文 NIAH/retrieval 结果不等价于长文综合推理。
- benchmark 结果来自不同 prompt/shot 设置，横向比较应看脚注。
- Claude Code 是模型之上的 agent/harness 产品，其文件工具、终端、权限、压缩和调度没有在本文作为完整架构公开。
