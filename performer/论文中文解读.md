## 一、一句话结论

标准（softmax）注意力要显式生成 $L\times L$ 的注意力矩阵，时间 $O(L^2d)$、空间 $O(L^2+Ld)$。Performer 的想法是：把核函数 $\exp(q^\top k)$ 写成**随机特征的内积**的期望，$\exp(q^\top k)=\mathbb{E}\big[\phi(q)^\top\phi(k)\big]$，于是可以利用矩阵乘法的结合律，**先**把所有 key 与 value 聚合成一个 $r\times d$ 的小矩阵，**再**让每个 query 去乘它，永远不构造 $L\times L$ 矩阵，时间降到 $O(Lrd)$，空间 $O(Lr+Ld+rd)$。作者把这个机制叫 **FAVOR+**（Fast Attention Via positive Orthogonal Random features），有三个关键点：

- **FA**：先聚合 $K'^\top V$ 再乘 $Q'$（结合律），双向、单向（因果，前缀和）两种情形都适用；
- **R+**：用**正**随机特征（positive random features，PRF）$\exp(\omega^\top x-\lVert x\rVert^2/2)$ 无偏地估计 softmax 核。以前常用的 $\sin/\cos$ 三角特征会出现负值，在核值接近 0 的位置方差很大，会让归一化分母变成负数、训练失败；
- **O**：让随机方向 $\omega_1,\dots,\omega_m$ **彼此正交**，在保持无偏的同时严格降低方差，并给出任意维度 $d$ 都成立的指数小的尾部界。

实验涉及蛋白质序列、图像像素和文本（含 PG-19）。需要特别注意：论文里**大多数“Performer”实验用的是 ReLU 广义注意力（不再是 softmax 的近似）**；真正的 softmax 近似版本叫 Performer-SOFTMAX，它的结果是与 Transformer“持平”（蛋白质双向任务上 33.00 对 33.32 的测试准确率），而不是“更好”。

## 二、背景：标准注意力与已有高效注意力路线

### 2.1 双向与单向注意力（原文式 1、2）

输入 $Q,K,V\in\mathbb{R}^{L\times d}$（$L$ 为序列长度，$d$ 为隐藏维度）。**双向**（非方向性，用于编码器自注意力和 encoder-decoder 注意力）：

$$
\mathrm{Att}_{\leftrightarrow}(Q,K,V)=D^{-1}AV,\qquad A=\exp\!\big(QK^\top/\sqrt d\big),\qquad D=\mathrm{diag}\big(A\mathbf 1_L\big),
$$

其中 $\exp$ 逐元素作用，$\mathbf 1_L$ 是全 1 向量，$\mathrm{diag}(\cdot)$ 把向量放到对角线上。$A$ 必须显式存储，所以时间 $O(L^2d)$、空间 $O(L^2+Ld)$。**单向**（因果，用于自回归生成）：

$$
\mathrm{Att}_{\rightarrow}(Q,K,V)=\widetilde D^{-1}\widetilde AV,\qquad \widetilde A=\mathrm{tril}(A),\qquad \widetilde D=\mathrm{diag}\big(\widetilde A\mathbf 1_L\big),
$$

$\mathrm{tril}(\cdot)$ 取下三角部分（含对角线）。论文称：这个 $A$ 可以在 $O(Ld^2\log d)$ 的时间内被近似到任意精度（对比基于 LSH 的稀疏方法的 $O(Ld^2\log L)$）。

### 2.2 已有路线与论文的评价（第 1 节）

- **稀疏/局部注意力**（局部邻域、Sparse Transformer、滑动窗口 Longformer 等）、**压缩**（Compressive Transformer）、**聚类/哈希**（Routing Transformer 用 k-means、Reformer 用 LSH）：不是在近似原注意力，而是换成更简单的机制，常带额外约束（如 Reformer 要求 query 与 key 集合相同）；论文认为它们缺乏对表示能力的严格保证，有的稀疏模式只能靠试错和手写 CUDA/TVM 算子来验证；
- **截断反向传播**（Transformer-XL）：梯度只在局部窗口内传播，抓不住长距离相关；
- **低秩/核方法**：Linformer（Wang 等 2020）有偏、只适用于非因果情形，且均方误差大；Katharopoulos 等（2020）、Shen 等（2018）的线性注意力要求核能写成有限的正特征向量的点积，但用的是别的核（如 $\mathrm{elu}+1$），不是对 softmax 的近似；
- Performer 声称是第一个能**可证明地、实用地**估计常规 softmax 满秩注意力、且只需线性时空复杂度、不依赖稀疏或低秩先验的架构；并且与已有 Transformer **向后兼容**（只需少量微调）。

可对照 [Linformer 解读](../linformer/论文中文解读.md)（低秩投影路线）。

## 三、方法一：FA——核化注意力与结合律（第 2.2 节）

### 3.1 广义可核化注意力（式 3、4）与图 1

FAVOR+ 适用于所有注意力矩阵形如 $A(i,j)=\mathcal K(q_i^\top,k_j^\top)$ 的情形，其中核 $\mathcal K:\mathbb{R}^d\times\mathbb{R}^d\to\mathbb{R}_+$ 可以通过一个（通常随机的）映射 $\phi:\mathbb{R}^d\to\mathbb{R}^r_+$ 表示成

$$
\mathcal K(x,y)=\mathbb{E}\big[\phi(x)^\top\phi(y)\big].
$$

$\phi$ 叫**随机特征映射**。令 $Q',K'\in\mathbb{R}^{L\times r}$ 的各行分别是 $\phi(q_i^\top)^\top$ 和 $\phi(k_i^\top)^\top$，则注意力可近似为

$$
\widehat{\mathrm{Att}}_{\leftrightarrow}(Q,K,V)=\widehat D^{-1}\Big(Q'\big((K')^\top V\big)\Big),\qquad \widehat D=\mathrm{diag}\Big(Q'\big((K')^\top\mathbf 1_L\big)\Big),
$$

括号表示计算顺序：先算 $(K')^\top V\in\mathbb{R}^{r\times d}$（$O(Lrd)$），再左乘 $Q'$（$O(Lrd)$）；分母同理：先算 $(K')^\top\mathbf 1_L\in\mathbb{R}^{r}$，再乘 $Q'$。空间复杂度 $O(Lr+Ld+rd)$，时间复杂度 $O(Lrd)$，对比标准注意力的 $O(L^2+Ld)$ 与 $O(L^2d)$。

![图 1：用（随机）特征映射近似注意力机制 AV（尚未做 D 的逆归一化）](rendered_figures/fig1-favor-attention-approximation.png)

*图 1（原文 Figure 1，第 3 页）：用（随机）特征映射近似常规注意力 $AV$（未做 $D^{-1}$ 归一化）；虚线框表示计算顺序，并标出相应的时间复杂度。*

**图中文字翻译与读法**：

- **左侧红色虚线框（attention mechanism，注意力机制）**：$L\times L$ 的注意力矩阵 $A$（蓝，带 batch dim 即批维度标记）与 $L\times d$ 的 $V$（黄）相乘，代价 $O(L^2d)$；
- **等号上的 $\mathbb{E}$**：右边是左边的期望（随机特征的期望等于真实的核）；
- **右侧红色虚线框**：$Q'$（红，$L\times r$）、$(K')^\top$（绿，$r\times L$）、$V$（黄，$L\times d$）三者连乘；其中**蓝色虚线框**圈出先算的 $(K')^\top V$，代价 $O(Lrd)$，随后 $Q'$ 乘这个结果，也是 $O(Lrd)$；
- **读图结论**：同一个乘积，左边必须先得到 $L\times L$ 矩阵，右边改变结合顺序后任何中间结果都不超过 $L\times r$ 或 $r\times d$，所以与 $L$ 线性相关。

**笔者补充的一个数值感受**：取 $L=4096$、每头 $d=64$、$r=256$：标准注意力的分数矩阵有约 1678 万个元素；FAVOR 的 $Q',K'$ 各约 105 万个元素，$(K')^\top V$ 只有 $256\times64=16384$ 个元素；在乘加次数上，标准做法是 $QK^\top$ 与 $PV$ 各 $L^2d$，合计约 $2L^2d\approx21.5$ 亿；FAVOR 要先算 $Q'$、$K'$（各约 $Lrd\approx6700$ 万），再做 $(K')^\top V$ 与左乘 $Q'$（各约 $Lrd$），合计约 $4Lrd\approx2.7$ 亿。按这个粗算，$L$ 小于约 $2r$（这里是 512）时 FAVOR 没有优势，这与图 3 中短序列时两者耗时相近一致。

### 3.2 单向（因果）情形：前缀和（附录 B.1，算法 1，图 A8）

单向注意力要求位置 $i$ 只能用 $j\le i$ 的 key、value。论文的做法是：令 $C=[V\ \mathbf 1_L]\in\mathbb{R}^{L\times(d+1)}$（把全 1 列并进来，一次算出分子和分母），要计算 $\mathrm{tril}\big(Q'(K')^\top\big)C$ 而不显式构造 $L\times L$ 矩阵。对第 $i$ 行：

$$
\big[\mathrm{tril}\big(Q'(K')^\top\big)C\big]_i=\big(G^{\mathrm{PS}}_{i}\big)^{\!\top}q'_i,\qquad G^{\mathrm{PS}}_{i}=\sum_{j=1}^{i}G_j,\qquad G_j=k'_j\,C_j^\top\in\mathbb{R}^{r\times(d+1)},
$$

其中 $q'_i,k'_j\in\mathbb{R}^r$ 是 $Q',K'$ 的第 $i$、$j$ 行（原文用三维张量 $G,G^{\mathrm{PS}}\in\mathbb{R}^{L\times r\times(d+1)}$ 的记号，式 11）。也就是说，把 key 的随机特征与 value 的外积沿位置做**累加和（prefix sum，前缀和）**，第 $i$ 个位置的输出只用当前前缀和乘以 $q'_i$。

**算法 1（FAVOR+，双向或单向）**：输入 $Q,K,V$ 和 isBidirectional 标志；计算 $Q',K'$，令 $C=[V\ \mathbf 1_L]$；若双向：$\mathrm{Buf}_1=(K')^\top C\in\mathbb{R}^{r\times(d+1)}$，$\mathrm{Buf}_2=Q'\mathrm{Buf}_1\in\mathbb{R}^{L\times(d+1)}$；若单向：按式 11 算前缀和张量 $G^{\mathrm{PS}}$，再逐行乘 $Q'_i$ 得 $\mathrm{Buf}_2$；然后把 $\mathrm{Buf}_2$ 拆成 $\mathrm{Buf}_3\in\mathbb{R}^{L\times d}$（分子）和 $\mathrm{buf}_4\in\mathbb{R}^{L}$（分母），返回 $\mathrm{diag}(\mathrm{buf}_4)^{-1}\mathrm{Buf}_3$。

![图 A8：单向注意力的前缀和算法示意](rendered_figures/figA8-prefix-sum-unidirectional.png)

*图 A8（原文 Figure 8，第 17 页）：单向注意力的前缀和算法示意（为清晰起见省略了归一化）。该算法维护一个前缀和矩阵，它由 key 的随机特征与 value 向量的外积逐个累加而成；每一步，把 query 的随机特征向量乘以最新的前缀和（即所有此前 token 的外积之和），得到 $AV$ 的新一行。*

**图中文字翻译与读法**：

- **左半**：下三角的紫色 $A$（因果 mask，只保留 $j\le i$，另标 batch dim 批维度）乘 $V$，等于右边由 $Q'$、$(K')^\top$、$V$ 三组叠片构成的乘积；
- **右半（红色虚线框内）**：沿位置排开的多层叠片，每一层对应一个位置；红色小箭头标出当前位置所用的 key 特征行与 value 行；$Q'$ 顶部的紫色虚线框标 $\phi(\mathbf q)$，即当前 query 的随机特征向量；右下角标出 outer product（外积，key 特征与 value 的外积）与 element of the prefix-sum（前缀和的一个元素）；
- **读图结论**：因果版本的状态是一个固定大小 $r\times(d+1)$ 的矩阵，每来一个新 token 只做一次累加；

复杂度（附录 B.3，笔者整理）：并行的前缀和需要 $O(\log L)$ 的并行时间和 $O(mLd)$ 的空间来存储 $G^{\mathrm{PS}}$；如果改用不并行（沿 $L$ 串行）的累加而不存整个张量，空间可降到 $O(md+Ld+mL)$。笔者注：这个串行形式就是“带固定大小状态的递推”，与后来的线性注意力递推形式一脉相承。

## 四、方法二：R+——如何（以及如何不）近似 softmax 核

### 4.1 随机特征的一般形式（式 5）

取函数 $f_1,\dots,f_l:\mathbb{R}\to\mathbb{R}$、函数 $h:\mathbb{R}^d\to\mathbb{R}$ 和独立同分布采样的 $\omega_1,\dots,\omega_m\sim\mathcal D$，令

$$
\phi(x)=\frac{h(x)}{\sqrt m}\Big(f_1(\omega_1^\top x),\dots,f_1(\omega_m^\top x),\ \dots,\ f_l(\omega_1^\top x),\dots,f_l(\omega_m^\top x)\Big),
$$

特征维度 $r=l\cdot m$。取不同的 $h,f_i$ 和分布 $\mathcal D$（常用各向同性的，通常是高斯）可以表示大多数常用的核：$h=1,l=1,\mathcal D=\mathcal N(0,I_d)$ 得到所谓 PNG 核（如 $f_1=\mathrm{sgn}$ 是夹角核）；$h=1,l=2,f_1=\sin,f_2=\cos$ 得到平移不变核，$\mathcal D=\mathcal N(0,I_d)$ 时是高斯核 $\mathcal K_{\text{gauss}}$（Rahimi & Recht 2007）。

### 4.2 softmax 核与三角随机特征的问题

定义 softmax 核 $\mathrm{SM}(x,y)=\exp(x^\top y)$（不失一般性略去 $1/\sqrt d$：可以等价地把 query 与 key 各乘 $d^{-1/4}$）。注意到

$$
\mathrm{SM}(x,y)=e^{\lVert x\rVert^2/2}\,\mathcal K_{\text{gauss}}(x,y)\,e^{\lVert y\rVert^2/2},\qquad \mathcal K_{\text{gauss}}(x,y)=e^{-\lVert x-y\rVert^2/2},
$$

（笔者验证：$\lVert x\rVert^2/2-\lVert x-y\rVert^2/2+\lVert y\rVert^2/2=x^\top y$。）于是可以用 $\sin/\cos$ 随机特征无偏地估计，取 $h(x)=e^{\lVert x\rVert^2/2}$、$l=2$、$f_1=\sin$、$f_2=\cos$，记作 $\widehat{\mathrm{SM}}^{\mathrm{trig}}_m(x,y)$。

**问题**：注意力给每个 token 构造的是 value 的**凸组合**，系数是归一化后的核分数，所以需要核值非负。随机特征的维度值若可能为负（$\sin/\cos$），则对于核值接近 0（大多数低相关度 token 的情形）的位置，估计量方差很大，可能出现“归一化分母 $D^{-1}$ 的对角元为负”等异常，要么无法训练，要么得到次优模型。作者认为这是此前没有人提出稳健的随机特征 softmax 近似的主要原因之一。

### 4.3 正随机特征（引理 1）

**引理 1（softmax 的正随机特征，PRF）**：对 $x,y\in\mathbb{R}^d$，令 $z=x+y$，则

$$
\mathrm{SM}(x,y)=\mathbb{E}_{\omega\sim\mathcal N(0,I_d)}\Big[\exp\!\Big(\omega^\top x-\frac{\lVert x\rVert^2}{2}\Big)\exp\!\Big(\omega^\top y-\frac{\lVert y\rVert^2}{2}\Big)\Big]=\Lambda\,\mathbb{E}_{\omega}\big[\cosh(\omega^\top z)\big],
$$

其中 $\Lambda=\exp\!\big(-(\lVert x\rVert^2+\lVert y\rVert^2)/2\big)$，$\cosh$ 是双曲余弦。

**证明（附录 F.1，笔者展开）**：先把 $\mathrm{SM}(x,y)=e^{-\lVert x\rVert^2/2}\,e^{\lVert x+y\rVert^2/2}\,e^{-\lVert y\rVert^2/2}$ 写开（展开 $\lVert x+y\rVert^2$ 即可验证）。再对标准高斯做配方：

$$
\mathbb{E}_{\omega\sim\mathcal N(0,I_d)}\big[e^{\omega^\top z}\big]=(2\pi)^{-d/2}\!\int e^{-\lVert w\rVert^2/2+w^\top z}\,dw=e^{\lVert z\rVert^2/2},
$$

（即高斯的矩母函数：把 $-\lVert w\rVert^2/2+w^\top z$ 配成 $-\lVert w-z\rVert^2/2+\lVert z\rVert^2/2$，剩下的积分为 1。）所以 $e^{\lVert x+y\rVert^2/2}=\mathbb{E}\big[e^{\omega^\top x}e^{\omega^\top y}\big]$，代入前式即得第一个等式。第二个等式：$\omega$ 与 $-\omega$ 同分布，所以 $\mathbb{E}[e^{\omega^\top z}]=\mathbb{E}[e^{-\omega^\top z}]=\mathbb{E}[\cosh(\omega^\top z)]$。

于是得到两种无偏的正随机特征估计：

- **$\widehat{\mathrm{SM}}^{+}_m$**：$h(x)=\exp(-\lVert x\rVert^2/2)$，$l=1$，$f_1=\exp$，$\mathcal D=\mathcal N(0,I_d)$，即 $\phi^{+}(x)_i=\frac1{\sqrt m}e^{\omega_i^\top x-\lVert x\rVert^2/2}$；所有分量恒为正，因此估计出的核值恒为正，$D^{-1}$ 不会出现负数；
- **$\widehat{\mathrm{SM}}^{\mathrm{hyp}+}_m$**：$h(x)=\frac1{\sqrt2}e^{-\lVert x\rVert^2/2}$，$l=2$，$f_1(u)=e^{u}$，$f_2(u)=e^{-u}$，同一个 $\mathcal D$；用成对的 $\pm\omega$ 进一步降低方差（上面的 $\cosh$ 形式）。

此外，若把引理 1（原文式 7）中的 $\omega$ 换成 $\sqrt d\,\omega/\lVert\omega\rVert$（即 $\mathcal D$ 换成半径 $\sqrt d$ 球面上的均匀分布，Haar 测度），得到**正则化 softmax 核** $\mathrm{SM}^{\mathrm{REG}}$ 及其估计 $\widehat{\mathrm{SM}}^{+\mathrm{REG}}_m$。

### 4.4 方差：正特征与三角特征的对比（引理 2、图 2）

**引理 2**：对独立采样的 $\omega_i$，均方误差（MSE）为

$$
\mathrm{MSE}\big(\widehat{\mathrm{SM}}^{\mathrm{trig}}_m\big)=\frac1{2m}\,e^{\lVert x+y\rVert^2}\,\mathrm{SM}^{-2}(x,y)\big(1-e^{-\lVert x-y\rVert^2}\big)^2,
$$

$$
\mathrm{MSE}\big(\widehat{\mathrm{SM}}^{+}_m\big)=\frac1m\,e^{\lVert x+y\rVert^2}\,\mathrm{SM}^{2}(x,y)\big(1-e^{-\lVert x+y\rVert^2}\big),
$$

$$
\mathrm{MSE}\big(\widehat{\mathrm{SM}}^{\mathrm{hyp}+}_m\big)=\frac12\big(1-e^{-\lVert x+y\rVert^2}\big)\,\mathrm{MSE}\big(\widehat{\mathrm{SM}}^{+}_m\big).
$$

后者说明双曲版本严格好于用两倍随机特征的 $\widehat{\mathrm{SM}}^{+}_{2m}$。

**笔者对证明的补充（附录 F.2）**：正特征的方差来自 $\mathrm{Var}\big(e^{\omega^\top z}\big)=\mathbb{E}\big[e^{2\omega^\top z}\big]-\big(\mathbb{E}\,e^{\omega^\top z}\big)^2=e^{2\lVert z\rVert^2}-e^{\lVert z\rVert^2}$（用到 $\mathbb{E}\,e^{2\omega^\top z}=e^{\lVert 2z\rVert^2/2}$）；估计量是 $\Lambda$ 乘上 $m$ 个独立项的均值，所以 $\mathrm{MSE}=\frac1m\Lambda^2\big(e^{2\lVert z\rVert^2}-e^{\lVert z\rVert^2}\big)$，再用 $\Lambda^2=\mathrm{SM}^2e^{-\lVert z\rVert^2}$ 就得到上式。三角特征的方差来自 $\mathrm{Var}\big(\cos(\omega^\top\Delta)\big)=\frac12\big(1-e^{-\lVert\Delta\rVert^2}\big)^2$（$\Delta=x-y$；由 $\mathbb{E}\cos u=e^{-s/2}$、$\mathbb{E}\cos 2u=e^{-2s}$，$u\sim\mathcal N(0,s)$ 算出）。

论文由此说：当 $\mathrm{SM}(x,y)\to0$ 时三角估计的 MSE 趋于 $\infty$，而正估计的 MSE 趋于 0。

- **左图（三维曲面）**：横向两个坐标轴分别是夹角 $\phi$ 和长度 $l$，竖轴是比值 $r$；曲面在 $\phi$ 较大（核值很小）的区域向上冲高；
- **右图**：横轴 $\phi$（范围约 $-18$ 到 $18$），纵轴 $r$（0 到约 18）；蓝色竖虚线标出 $\phi=\pm\pi,\pm3\pi,\pm5\pi$（两向量反向的位置），红色曲线在这些位置趋于无穷，在 $\phi$ 为 $2\pi$ 的整数倍（两向量同向）处接近 0；
- **右上角小图**：蓝色框，三维曲面上标 TRIG（三角特征）的 MSE 远高于标 POS（正特征）的 MSE；
- **读图结论**：在关键区域（核值很小、需要精细逼近的位置）正特征可以比三角特征精确得多；

**笔者核算（单位向量情形）**：取 $\lVert x\rVert=\lVert y\rVert=1$、夹角 $\varphi$，则 $\mathrm{SM}=e^{\cos\varphi}$，$\lVert x-y\rVert^2=2(1-\cos\varphi)$，$\lVert x+y\rVert^2=2(1+\cos\varphi)$。代入引理 2，下表是乘以特征数 $m$ 之后的 MSE（即 $m\cdot\mathrm{MSE}$）：

| 夹角 $\varphi$ | $\mathrm{SM}(x,y)$ | 三角特征 | 正特征 $+$ | 双曲正特征 $\mathrm{hyp}+$ |
|---:|---:|---:|---:|---:|
| 0°（同向） | 2.718 | 0 | 396.0 | 194.4 |
| 90°（正交） | 1.000 | 2.762 | 6.389 | 2.762 |
| 135° | 0.493 | 3.455 | 0.194 | 0.043 |
| 180°（反向） | 0.368 | 3.560 | 0 | 0 |

笔者另用 $d=8$、40 万个样本做了蒙特卡洛模拟，对 90°、135°、180° 三行核验，与公式在约 2% 以内吻合。读法：**正特征并非处处更准**——同向（核值大）时三角特征几乎无误差，正特征反而误差大（相对误差 $\mathrm{MSE}/\mathrm{SM}^2$ 约 $53.6/m$）；但在反向、核值小的位置，正特征的方差趋于 0（$\varphi=180^\circ$ 时 $x+y=0$，$e^{\omega^\top z}\equiv1$，估计量是常数，无误差），三角特征则仍有 $3.56/m$ 的方差，相对误差约 $26/m$。这与论文的论点一致：低相关度 token 的核值小，需要小的**相对**误差，否则会被归一化放大。

### 4.5 正则化 softmax 核（定理 1）

**定理 1（正则化 softmax 核对 softmax 核）**：设 softmax 核的注意力矩阵满足 $\lVert A\rVert_\infty\le C$（$C\ge1$ 为常数），$A^{\mathrm{reg}}$ 为对应的正则化核的注意力矩阵，则

$$
\inf_{i,j}\frac{A^{\mathrm{reg}}(i,j)}{A(i,j)}\ \ge\ 1-\frac{2}{d^{1/3}}\Big(1+o\big(d^{-1/3}\big)\Big),\qquad \sup_{i,j}\frac{A^{\mathrm{reg}}(i,j)}{A(i,j)}\le1.
$$

并且后一个不等式在 $d\ge2$ 时即使不满足范数条件也成立：正则化 softmax 核是 softmax 核的**通用下界**。因此对 $\mathrm{SM}^{\mathrm{REG}}$ 用正随机特征也可以逼近 softmax 核。（笔者注：$d=64$ 时 $d^{1/3}=4$，下界系数约 $1-2/4=0.5$，对常见的 head 维度并不紧，是渐近结论。）

## 五、方法三：O——正交随机特征（第 2.4 节）

**构造**：为进一步降低估计量的方差（从而能使用更少的随机特征 $r$），让 $\omega_1,\dots,\omega_m$ **彼此严格正交**。只要分布 $\mathcal D$ 是各向同性的（本文所有的核都满足），就可以用标准的 Gram–Schmidt 正交化在保持无偏的前提下做到。要求 $m\le d$；若需要 $m>d$，可以在每个 $d\times d$ 块内使用 ORF（附录 B.2）。（笔者补充：标准做法是对 $d\times d$ 的高斯矩阵做 QR 正交化，再把每一行的模长重新抽成与 $\lVert\omega\rVert$ 同分布的独立值，这样每个 $\omega_i$ 的边缘分布仍是 $\mathcal N(0,I_d)$。）

**理论结果**：

**定理 2（正交降低均方误差）**：若 $\widehat{\mathrm{SM}}^{\mathrm{ort}+}_m$ 是用正交特征（$m\le d$）的 $\widehat{\mathrm{SM}}^{+}_m$，则对任意 $d>0$：

$$
\mathrm{MSE}\big(\widehat{\mathrm{SM}}^{\mathrm{ort}+}_m(x,y)\big)\ \le\ \mathrm{MSE}\big(\widehat{\mathrm{SM}}^{+}_m(x,y)\big)-\frac{2(m-1)}{m(d+2)}\Big(\mathrm{SM}(x,y)-e^{-\frac{\lVert x\rVert^2+\lVert y\rVert^2}{2}}\Big)^2.
$$

对正则化的 $\mathrm{SM}^{\mathrm{REG}}$ 有完全类似的结论。这是**第一个**说明正交随机特征可以对**任意**维度 $d$（而不仅是 $d$ 足够大时的渐近意义）降低 softmax/高斯核估计方差的理论结果。

其余结果：

- **定理 3（正交的尾部界）**：对 $\mathrm{SM}^{\mathrm{REG}}$，对任意 $a>\mathrm{SM}^{\mathrm{REG}}(x,y)$、$\theta>0$、$m\le d$，独立特征的上尾概率有 $\exp(-\theta ma)M_Z(\theta)^m$ 的界（$M_Z$ 为矩母函数），正交特征在此基础上再减去一个正项（含 $\theta^4m(m-1)/(4(d+2))\cdot\lVert x+y\rVert^4$ 的因子）。即正交特征给出**指数小且严格更紧**的尾部界，在核值小的关键区域尤其明显；正特征（正性）在这些界里起关键作用。
- **更一般的结果（附录 F.4，笔者概括）**：论文把这些结果推广到“美丽函数”（beautiful functions）$F_{\Omega,g}(z)=\mathbb{E}_{\omega\sim\Omega}[g(\omega^\top z)]$，其中 $g$ 是幂级数系数非负的整函数；$\mathrm{SM}$ 对应 $g=\exp$。定理 5 与 6 给出任意此类函数的尾部界与 MSE 改进：$\mathrm{MSE}(\widehat F^{\mathrm{ort}}_m)\le\mathrm{MSE}(\widehat F^{\mathrm{iid}}_m)-(1-\frac1m)\frac{2}{d+2}\big(F_{\Omega,g}(z)-a_0\big)^2$，其中 $a_0=g(0)$；定理 2、3 是它们的特例。（代入 $g=\exp$、$a_0=1$、乘以 $\Lambda$，就得到定理 2 的括号 $\mathrm{SM}-\Lambda$，笔者验证。）
- **ORF 的变体（附录 B.2）**：Regular ORF（高斯正交矩阵，$O(md)$ 空间、$Wx$ 需 $O(md)$ 时间、无偏，一次性 $O(md^2)$ 预处理）；Hadamard/Givens ORF（空间 $O(m)$ 或 $O(m\log d)$、$Wx$ 需 $O(m\log d)$ 时间、有小偏差且随 $d\to\infty$ 趋于 0）。

## 六、理论保证总览与边界

### 6.1 均匀收敛（定理 4）

**定理 4**：设 query/key 的 $L_2$ 范数都不超过 $R>0$。令 $l=R\,d^{-1/4}$，$h^*=\exp(l^2/2)$。则对任意 $\epsilon>0$，取 $\delta=\epsilon/(h^*)^2$，随机投影数

$$
m=\Theta\Big(\frac{d}{\delta^2}\log\frac{4d^{3/4}R}{\delta}\Big)
$$

时，用**三角特征加正交特征**的 $\widehat{\mathrm{SM}}^{\mathrm{trig}}$ 近似注意力矩阵，以任意常数概率有 $\lVert\widehat A-A\rVert_\infty\le\epsilon$。要点：$m$ 依赖于维度 $d$、精度 $\epsilon$ 和半径 $R$，**不依赖序列长度 $L$**；论文说由此取 $m=\Theta(d\log d)$ 即可，时间为 $O(Ld^2\log d)$。论文还说，即使是三角特征加 ORF 也只需 $m=\Theta(d\log d)$ 个特征（“如果不是因为注意力的归一化，就不需要 PRF 了”）。

### 6.2 笔者的几点提醒

1. **无偏性只对未归一化的核成立**：$\mathbb{E}\big[\phi(q)^\top\phi(k)\big]=\exp(q^\top k)$，即 $A$ 的每个元素的估计是无偏的；但实际输出 $\widehat D^{-1}\big(Q'(K'^\top V)\big)$ 含一个对随机量的除法，$\mathbb{E}[X/Y]\ne\mathbb{E}[X]/\mathbb{E}[Y]$，所以有限 $m$ 下归一化后的输出是有偏的（一致、近似无偏），摘要里写的是“unbiased or nearly-unbiased”。
2. **定理 4 针对的是三角特征，不是实际使用的 PRF**：PRF 有 MSE 与尾部界（定理 2、3），但论文没有给出 PRF 的均匀收敛定理。
3. **依赖半径 $R$**：论文自己在附录 F.6 指出，查询与键的长度不能随序列增长而无限增大，否则固定 $m$ 下近似质量会下降；FAVOR **不能用固定的 $m$ 近似无限长序列上的硬注意力**（即 softmax 集中到单个元素）。论文说这在其实验的长度范围内没有表现出来。
4. **ORF 要求 $m\le d$**：实际默认 $m=256$、每头维度 $d=512/8=64$（笔者按“regular”配置推算），用的是分块正交，定理对块之间的相关性没有覆盖。
5. **误差可逐层累积**：见下文图 A14，近似很紧的注意力，误差也会经多层放大。

### 7.6 长序列训练：ImageNet64 与串接蛋白质（第 4.5 节，图 7）

**ImageNet64（单向）**：标准 (U) 基准（Parmar 等 2018），$L=12288$（$64\times64$ 像素 $\times3$ 通道），常规 Transformer 无法训练。所有模型使用相同的 $(n_{\text{heads}},d_{ff},d)=(8,2048,512)$，只改变层数。

**串接 TrEMBL（双向）**：把蛋白质序列串接到 $L=8192$，用来做“预测蛋白质群之间相互作用”的原理验证研究（长度足以建模蛋白质相互作用网络，而不需要现有方法所需的大规模序列比对）。常规 Transformer 在这个设置下即使每片 batch 为 1 也远远超出内存，所以基线被迫缩成 $(n_{\text{heads}},n_{\text{layers}},d_{ff},d)=(8,\{1,2,3\},256,256)$；Performer 则用标准的 $(8,6,2048,512)$ 在每片 batch 为 8 下高效训练。

![图 7：ImageNet64（L=12288）和串接 TrEMBL（L=8192）上的训练](rendered_figures/fig7-imagenet64-and-concat-trembl.png)

- **左图 ImageNet64 ($L=12288$)**：横轴 Steps（0 到约 10 万），纵轴 BPD（每维比特数，3.4 到 4.6，越低越好）；图例 Performer-RELU 6L、12L（蓝），Reformer 6L、12L、18L、24L（浅红到深红）；

## 八、局限、证据边界与常见误读

**论文的主要证据边界**：

1. **“Performer”是什么要看后缀**：多数大实验用的是 ReLU 广义注意力，它并不近似 softmax；而近似 softmax 的 Performer-SOFTMAX 只是“追平”而非超过 Transformer，并且要靠重抽样等技巧才稳定；
2. **理论与实际的距离**：均匀收敛定理针对三角特征；PRF 的保证是 MSE 与尾部界；定理 1 的系数对常见维度并不紧；
3. **向后兼容需要微调**：预训练权重不能直接用，因为误差经多层传播（图 A14），LM1B 上需要在原始步数的一小部分内恢复；
4. **OOD 不占优**：附录表 2 中 Performer 在 OOD 集上都低于 Transformer；
5. **对比的公平性**：batch 取各自最大值；ImageNet64、串接蛋白质的基线规模不同；Linformer 基线用了作者自己的 Jax 实现与 $k=600$；Linear Transformer 只在一组超参数下比较；几乎没有多次运行的方差；
6. **LRA 的数字来自另一篇论文**，且 Performer 的优势只在 0.02 到 0.05 的量级；
7. **短序列没有优势**：按 3.1 节的粗算，序列长度小于约 $2r$ 时 FAVOR 不占优（图 3 的短序列两者耗时相近）；每头维度较大时 $m=\Theta(d\log d)$ 也不小。

**常见误读**：

- Performer 的“线性”是对序列长度而言，代价里仍有 $d$ 与特征数 $r$；它是统计近似，不是对 softmax 的精确重排；“理论无偏”只对未归一化核的每个元素成立，一次有限随机映射不是没有误差；
- Performer 不是“去掉 softmax”：FAVOR+ 的目标是近似 $\exp(q^\top k)$ 核；若换成 ReLU 等核，就是另一种线性注意力（“广义注意力”）；
- 因果版本不能把未来的 key、value 加进全局和；要用前缀和。

## 九、复现检查清单

- 用论文的正随机特征映射 $\exp(\omega^\top x-\lVert x\rVert^2/2)$，并先把 query、key 各乘 $d^{-1/4}$；用 $\sin/\cos$ 的随机傅里叶特征不能直接等价；注意数值稳定化（论文默认 numerical stabilizer $10^{-6}$）；
- 分母必须一并近似：$\widehat D=\mathrm{diag}\big(Q'(K'^\top\mathbf 1_L)\big)$；漏掉归一化就变成另一种线性注意力；
- 因果实现用前缀和（或串行累加），禁止把未来的 $K',V$ 加入全局和；
- ORF：$m\le d$ 时用 Gram–Schmidt（QR），$m>d$ 时分块；周期性重抽样随机矩阵（论文认为这对大规模训练很关键）；
- 记录特征数（默认 256）、核（softmax 近似或 ReLU）、是否重抽样、是否 SMREG、numerical stabilizer；
- 多个随机种子报告方差，并扫描特征数 $r$；比较时保持每步样本数一致，或明确说明 batch 的差异。

## 十、与相关论文的关系

- [Linformer](../linformer/论文中文解读.md)：低秩投影路线，只适用于非因果；本文把它作为 (B) 基线，在蛋白质和 PG-19 上表现较差（用 $k=600$）；Performer 的路线是近似 softmax 核本身；
- [RoPE](../rope/论文中文解读.md)：RoPE 论文第 4.4 节把旋转位置编码加到 Performer 上，证明旋转可以与线性注意力结合；
- [FlashAttention](../flash_attention/论文中文解读.md)：该论文的表 3（Long-Range Arena）里也有 Performer（平均精度 58.9，对标准 Transformer 的 59.3，加速 1.8 倍；来自 FlashAttention 论文自己的复现）；FlashAttention 保持精确注意力、优化访存，与近似路线互补；
- [Longformer](../longformer/论文中文解读.md)、[BigBird](../bigbird/论文中文解读.md)：稀疏图路线；
- Katharopoulos 等 2020（Linear Transformer，$\mathrm{elu}+1$）：线性注意力的另一条路线，本文表明在其设置下它训练不稳定。
