# Ada-MK 论文概要

## 基本信息

- 题目：*Ada-MK: Adaptive MegaKernel Optimization via Automated DAG-based Search for LLM Inference*
- 作者：Wenxin Dong 等
- 版本：arXiv:2605.11581，2026 预印本
- 原文：https://arxiv.org/abs/2605.11581
- 主题：Ada GPU、离线 DAG 搜索、MegaKernel、TensorRT-LLM 集成

## 一句话结论

Ada-MK 面向 shared memory 更紧、无 TMA 的 NVIDIA Ada/L20，把 MegaKernel 的资源分配与执行路径在部署配置确定后离线搜索并固化，再作为 TensorRT-LLM plugin 只替换 decode 路径，以避免通用设备侧动态调度的分支开销。

## 核心方法

- 三维资源模型同时考虑 GPU、模型结构与 workload。
- K-dimension splitting 将峰值 shared-memory 需求降低约 50%。
- shared-memory page reuse 跨 operator 复用 buffer。
- MLIR lowering 与 alias/dependency analysis 构建细粒度 DAG。
- 搜索 warp role、pipeline stage、prefetch 和页面分配，并在编译期固定路径。
- Prefill 保留 TensorRT-LLM 原生执行，decode 切到 MegaKernel。

## 主要结果

- L20、Qwen3-1.7B/Qwen2.5-1.5B、GPTQ-W4A16。
- input 64/output 12：相对 vanilla TensorRT-LLM 全 batch 均提升，Qwen3 batch 1 最高 23.6%；Qwen2.5 为 6.7%–15.6%。
- CSL 长度分布下 batch 1–8 最快，但 batch 16 被 vLLM 超过 3.5%。
- HumanEval batch 16 仍相对 TensorRT-LLM 提升 19.5%，对 vLLM/SGLang 优势缩小。

## 局限

- 仅单张 L20、两个 1.5B–1.7B 量化模型，结论范围窄。
- offline batch throughput 不等价于在线 SLO。
- 论文把“首次工业部署”等陈述作为作者报告，缺少独立复验。
- 固定配置利于 compile-time specialization，但模型/shape/硬件变化可能要求重新搜索。

## 阅读价值

Ada-MK 展示了 MegaKernel 的另一端设计：不是引入更通用 runtime，而是利用部署配置固定这一事实，将控制决策尽量前移，并与成熟 TensorRT-LLM 做异构集成。
