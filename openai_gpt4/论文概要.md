# 论文概要：《GPT-4 Technical Report》

## 一、基本信息

- 作者：OpenAI
- 公开时间：2023-03，arXiv:2303.08774
- 定位：可接受图像/文本输入、输出文本的多模态模型技术报告与系统卡
- 开放边界：没有公开参数量、层数、数据、计算量、训练代码或权重
- 本地材料：[论文 PDF](paper.pdf) · [提取文本](paper.txt) · [中文精读](论文中文解读.md)

## 二、一句话结论

GPT-4 报告最实质的技术内容是“可预测 scaling”：用计算量至多小 1000× 的模型预测最终 loss 和 HumanEval；能力、安全与多模态评估很丰富，但架构细节几乎未披露，因此它是能力/部署报告，不是可复现架构论文。

## 三、公开了什么

- Transformer-based next-token prediction + RLHF 的高层描述。
- loss 与 HumanEval 随 compute scaling 的外推方法。
- 专业考试、MMLU、多语言和视觉输入评测。
- 幻觉、校准、红队、安全 reward model 与部署缓解。

## 四、没有公开什么

- 参数量、层数、hidden size、attention/MoE 结构；
- 训练 token、数据构成、训练 FLOPs 与硬件；
- 视觉 encoder/connector；
- checkpoint、训练代码与完整数据。

## 五、局限

- 报告明确指出 GPT-4 仍会 hallucinate、推理错误，知识有截止日期。
- RLHF 后校准可能变差，即更会按目标回答不代表置信度更可信。
- benchmark 可能污染，且考试成绩不能替代真实可靠性。
- 因披露有限，外界不能从本文验证流行的 MoE/参数量传言。
