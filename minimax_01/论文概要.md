# 论文概要：《MiniMax-01: Scaling Foundation Models with Lightning Attention》

## 一、基本信息

- 作者：MiniMax
- 公开时间：2025-01，arXiv:2501.08313
- 模型：MiniMax-Text-01、MiniMax-VL-01
- 规模：456B 总参数，45.9B 每 token 激活，32 experts/top-2
- 核心主题：Lightning Attention + softmax attention + MoE 的混合架构
- 本地材料：[论文 PDF](paper.pdf) · [提取文本](paper.txt) · [中文精读](论文中文解读.md)

## 二、一句话结论

MiniMax-01 用 7 层 lightning attention + 1 层 softmax attention 的周期混合，把线性 attention 的长序列效率与 full attention 的全局建模结合，再用 MoE 扩容量；模型训练到 1M context，并在 NIAH 上外推到 4M，但“可接收 4M”不等于在 4M 上所有推理任务都可靠。

## 三、架构

- 80 层，hidden size 6144。
- 每 7 个 lightning/TransNormer block 后放 1 个 softmax attention block。
- attention 为 64 heads × 128 dim；softmax 层用 GQA group size 8。
- 每层 32 个 FFN experts，top-2；expert hidden size 9216。
- 使用 DeepNorm、global router 与 token-drop MoE。

## 四、系统与训练

- Lightning Attention 把 causal attention 拆成 block 内左乘和 block 间右乘，避免逐 token cumsum 的低并行效率。
- LASP+、varlen ring attention、Expert Tensor Parallel 等支持百万 context 与 MoE。
- 初始训练约 11.4T tokens，随后分阶段扩到 1M context；MiniMax-VL-01 再训练 512B vision-language tokens。
- 后训练包含 SFT、offline/online RL 与多类 reward model。

## 五、局限

- 4M 主要由 NIAH 压力测试支持，报告自己也指出 NIAH 很早饱和。
- hybrid linear attention 的数值/精度和 kernel 兼容性比标准 softmax 复杂。
- token dropping、global routing 与跨 EP all-gather 可能引入负载和通信代价。
- 模型权重公开，但模型许可证不是统一意义上的 Apache/MIT；训练全栈也未完整开放。
