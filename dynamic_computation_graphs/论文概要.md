# Deep Learning with Dynamic Computation Graphs 论文概要

## 基本信息

- 题目：*Deep Learning with Dynamic Computation Graphs*
- 作者：Moshe Looks、Marcello Herreshoff、DeLesley Hutchins、Peter Norvig
- 会议：ICLR 2017
- 原文：[arXiv:1702.02181](https://arxiv.org/abs/1702.02181)
- 本地文件：[paper.pdf](paper.pdf)｜[paper.txt](paper.txt)

## 一句话结论

当每个样本的计算图形状不同，dynamic batching 可以按 operation signature 与拓扑深度自动把可并行节点拼成 batch，再用一张静态 dataflow graph 执行异构树和图结构。

## 核心算法

1. 用户为每个样本建立输入相关的动态操作图。
2. 对节点按依赖深度分层。
3. 在同一深度，把具有相同 operation/type signature 的节点组成 batch。
4. 用 gather 收集输入、执行一次 batched op，再用 concat 保存输出状态。
5. 通过静态 while_loop 逐层消费 schedule。

## 关键结果

- 对大小为 128 的 Tree-LSTM，单样本 GPU 上 dynamic batching 相对逐节点执行约 4.47×。
- 相对 batch size 1 的逐树执行，论文报告随机形状树在 GPU 上最高约 120×、CPU 上约 28×。
- 额外 gather/concat 并非免费；大 batch 时，动态图调度的额外代价可能超过手工完美 batching。

## 应用

- parse tree 上的 Tree-LSTM；
- 变长序列和 attention；
- molecule graph convolution；
- 递归、分支和组合式神经网络。

## 主要局限

- 实现依托 TensorFlow Fold，系统已不是主流生产栈。
- 基准中的“manual batching”要求树形相同，是特意构造的上界对照。
- 算法解决异构图节点 batching，不等同于 PyTorch 2 的 graph capture 或 symbolic shape。

## 阅读价值

它展示了动态图的核心工程矛盾：灵活拓扑会破坏规则 batch，而性能来自重新发现跨样本、甚至单样本内部的可批处理结构。
