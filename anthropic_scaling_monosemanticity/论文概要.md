# 论文概要：《Scaling Monosemanticity: Extracting Interpretable Features from Claude 3 Sonnet》

## 一、基本信息

- 作者：Adly Templeton、Tom Conerly、Jonathan Marcus 等，Anthropic
- 首次公开：2024-05，Transformer Circuits Thread；后收入 arXiv:2605.29358
- 研究对象：Claude 3.0 Sonnet 中间层 residual stream
- 核心方法：大规模 Sparse Autoencoder（SAE）与 feature steering
- 本地材料：[论文 PDF](paper.pdf) · [提取文本](paper.txt) · [中文精读](论文中文解读.md)

## 二、一句话结论

Anthropic 在 Claude 3 Sonnet 中间层训练 1M、4M、34M feature 的 SAE，从混合神经激活中分解出大量可解释、跨语言、跨模态的 feature，并通过 steering/ablation 展示部分因果作用；但 SAE 只能近似重构一层激活，feature 不完备、许多 dead，解释也不等于模型完整计算图。

## 三、核心设置

- SAE encoder 将 residual activation 映射到高维稀疏 feature，再由 decoder 重构。
- loss = reconstruction error + L1 sparsity penalty。
- 三个 SAE 分别约 1M、4M、34M features；每 token 平均激活少于 300 个。
- 至少解释约 65% activation variance；规模越大 dead feature 比例也显著上升。
- 用 Claude 自动解释、人类检查、steering、ablation 与 attribution 评估 feature。

## 四、代表发现

- 找到 Golden Gate Bridge、人物、地点、代码错误、函数调用、列表位置等 feature。
- 一些 feature 对多语言和图像中的同一概念响应。
- 找到与欺骗、权力寻求、谄媚、偏见和危险内容相关的候选 feature。
- 提高特征激活可改变输出，说明至少部分不是纯相关探针。

## 五、局限

- Claude 仍是专有模型，隐藏维度、模型大小和若干坐标未公开。
- SAE 重构有残差，未表示部分可能包含关键计算。
- feature 的语义标签依赖有限样本和解释者，可能过度概括。
- steering 强度远超自然分布时产生的行为不能证明正常推理同样依赖该 feature。
- 单层 feature 不给出跨层因果 circuit；后续 Circuit Tracing 才进一步处理连接。
