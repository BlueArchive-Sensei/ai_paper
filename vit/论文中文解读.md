## 一、一句话结论

Vision Transformer（ViT）把图像切成固定大小的小块（patch，如 $16\times16$ 像素），每个 patch 展平后用一个线性层映射成一个向量，当作 NLP 里的“词”；加上位置编码和一个额外的可学习 `[class]` 向量，直接送进**标准的** Transformer 编码器，用 `[class]` 位置的输出做分类。除了“切 patch”这一步，整个网络没有任何图像专用的结构（没有卷积，没有金字塔）。

结论是有条件的：

- 在 ImageNet 这类中等规模数据上从头训练（没有很强的正则化），ViT 比同量级的 ResNet 低几个百分点，因为缺少卷积自带的**平移等变**和**局部性**这两种归纳偏置；
- 预训练数据扩大到 1400 万（ImageNet-21k）到 3 亿张（JFT-300M）之后，情况反转，作者的说法是“**大规模训练胜过归纳偏置**”：最好的模型 ViT-H/14（JFT-300M 预训练）在 ImageNet 上 88.55%、ImageNet-ReaL 90.72%、CIFAR-100 94.55%、19 项 VTAB 平均 77.63%；
- 同时预训练算力更省：ViT-H/14 用 2.5k TPUv3-core-days，BiT-L（ResNet152x4）要 9.9k，Noisy Student（EfficientNet-L2）要 12.3k；在受控的缩放实验里，ViT 达到同样精度所需的预训练算力约少 $2$–$4$ 倍；
- 但在小数据（ImageNet 从头训练，或 JFT 的 9M 子集）上，ViT 反而不如 ResNet；这个“数据规模依赖”本身就是论文的核心结论之一。

## 二、背景与动机

### 2.1 为什么要把 Transformer 直接用到图像上

在 NLP 里，Transformer 已是事实标准：先在大语料上预训练，再在小的任务数据集上微调（BERT）；得益于计算效率和可扩展性，模型已经能训练到超过 1000 亿参数（GPT-3、GShard），而且“没有看到性能饱和的迹象”。

在计算机视觉里，卷积网络（LeCun 1989、AlexNet、ResNet）仍占主导。已有的尝试大致有两类：把 CNN 式结构与自注意力结合（non-local 网络、DETR 等），或者干脆完全用自注意力替代卷积（stand-alone self-attention、axial attention 等）。后者理论上高效，但因为使用了**专门设计的注意力模式**，还没能在现代加速器上有效地扩大规模；所以在大规模图像识别里，最强的仍是 ResNet 一类结构（BiT、Noisy Student 等）。

论文的做法是反过来：**用尽可能少的改动把标准 Transformer 直接用到图像上**。作者想验证的是：如果不加任何图像特有的结构，只靠足够大的数据，Transformer 能不能追上卷积网络。

### 2.2 相关工作（原文第 2 节）

- 朴素的做法是让每个像素关注所有其他像素，成本随像素数二次增长，无法用于真实尺寸的图像。因此过去尝试了各种近似：只在每个 query 像素的局部邻域内做自注意力（Image Transformer；局部多头点积自注意力块可以完全替代卷积）、Sparse Transformers（对全局注意力的可扩展近似）、在不同大小的块内做注意力，极端情况下沿单个坐标轴做（axial attention）。这些专用的注意力结构在视觉任务上结果不错，但需要复杂的工程才能在加速器上高效实现。
- 与本文最接近的是 Cordonnier 等人（2020）：从输入图像中提取 $2\times2$ 的 patch 再做全局自注意力，与 ViT 非常相似。区别在于：本文进一步证明大规模预训练能让**原版** Transformer 与最先进的 CNN 竞争甚至更好；而且他们用 $2\times2$ 的小 patch，只适用于小分辨率图像，本文还能处理中等分辨率。
- 另有大量工作把 CNN 与某种自注意力结合：增强特征图、或用自注意力进一步处理 CNN 的输出（目标检测、视频、图像分类、无监督目标发现、图文联合任务）。
- **iGPT**（image GPT）：把图像降低分辨率和色彩空间后，对像素序列用 Transformer 做生成式无监督训练，所得表示可微调或线性探测，ImageNet 最高 72%。
- 在比 ImageNet 更大的数据上探索图像识别的工作：用额外数据源能在标准基准上取得 SOTA；有研究 CNN 性能如何随数据规模变化，也有对 CNN 从 ImageNet-21k 和 JFT-300M 迁移的经验研究。本文也聚焦这两个数据集，但训练的是 Transformer 而不是 ResNet。

## 三、方法（原文第 3 节）

### 3.1 整体结构

![图 1：ViT 模型概览](rendered_figures/fig1-vit-overview.png)

*图 1（原文 Figure 1，第 3 页）：把图像切成固定大小的 patch，对每个 patch 做线性嵌入，加上位置编码，把得到的向量序列送入标准 Transformer 编码器；为了做分类，采用标准做法，在序列前面加一个额外的可学习“分类 token”。右侧 Transformer 编码器的示意受 Vaswani 等人启发。*

**图中文字翻译与读法**：

- **左：Vision Transformer (ViT)**。底部是被切成 9 块的输入图像（示意图用 $3\times3$ 个 patch），每块展平后经 **Linear Projection of Flattened Patches**（展平 patch 的线性投影）得到 patch 向量；每个 patch 向量旁边带编号 1–9 的紫色小块是它的**位置编码**（图左标注 **Patch + Position Embedding**）；编号 0、带星号的那一格是额外的可学习 `[class]` 嵌入（图注 “* Extra learnable [class] embedding”）。所有向量一起送入 **Transformer Encoder**，取 `[class]` 位置的输出送给 **MLP Head**，输出类别（**Class**：Bird、Ball、Car 等）。
- **右：Transformer Encoder**。重复 $L$ 次的块（图中标 “L ×”），自下而上：输入 **Embedded Patches**（嵌入后的 patch）$\to$ **Norm** $\to$ **Multi-Head Attention**（Norm 下面分出的三条箭头表示同一个归一化后的输入同时作为 $q,k,v$）$\to$ 加号（残差连接）$\to$ **Norm** $\to$ **MLP** $\to$ 加号（残差连接）。
- **读图结论**：整条流水线是“切块 $\to$ 线性投影 $\to$ 加位置编码和 `[class]` $\to$ 若干层标准的 pre-norm Transformer 块 $\to$ 读 `[class]` 输出”，和 BERT 的结构几乎一样。

### 3.2 Patch 嵌入、位置编码与 `[class]` token

标准 Transformer 接收的是一维的 token 嵌入序列。为处理二维图像，把图像 $x\in\mathbb{R}^{H\times W\times C}$ 重塑为展平的二维 patch 序列 $x_p\in\mathbb{R}^{N\times(P^2\cdot C)}$：

- $(H,W)$ 是原图分辨率，$C$ 是通道数（RGB 图为 3）；
- $(P,P)$ 是每个 patch 的分辨率；
- $N=HW/P^2$ 是 patch 个数，也就是 Transformer 实际看到的**序列长度**。

Transformer 的所有层都使用恒定的隐向量维度 $D$，所以把每个展平的 patch 用一个可训练的线性投影 $E$ 映射到 $D$ 维（式 1），投影的输出叫**patch 嵌入**。

仿照 BERT 的 `[class]` token，在 patch 嵌入序列前面加一个可学习的嵌入 $z_0^0=x_{\text{class}}$，它在 Transformer 编码器输出处的状态 $z_L^0$ 作为整张图的表示 $y$（式 4）。预训练和微调时，分类头都接在 $z_L^0$ 上：**预训练时是带一个隐藏层的 MLP，微调时是单个线性层**。

**位置编码**加到 patch 嵌入上以保留位置信息。论文用标准的**可学习一维位置编码**，因为没有观察到更高级的二维感知位置编码带来明显提升（附录 D.4，见第六节）。得到的嵌入向量序列就是编码器的输入。

**Transformer 编码器**由多头自注意力（MSA，附录 A）与 MLP 块交替叠成（式 2、3）：每个块之前做 LayerNorm（LN），每个块之后做残差连接；MLP 含两层，中间用 GELU 非线性。完整的前向为

$$
z_0=[x_{\text{class}};\ x_p^1E;\ x_p^2E;\ \cdots;\ x_p^NE]+E_{\text{pos}},\qquad E\in\mathbb{R}^{(P^2\cdot C)\times D},\quad E_{\text{pos}}\in\mathbb{R}^{(N+1)\times D}\qquad(1)
$$

$$
z'_\ell=\mathrm{MSA}\big(\mathrm{LN}(z_{\ell-1})\big)+z_{\ell-1},\qquad \ell=1,\dots,L\qquad(2)
$$

$$
z_\ell=\mathrm{MLP}\big(\mathrm{LN}(z'_\ell)\big)+z'_\ell,\qquad \ell=1,\dots,L\qquad(3)
$$

$$
y=\mathrm{LN}\big(z_L^0\big)\qquad(4)
$$

逐项读法：

- 式 (1)：序列由 $N+1$ 个 $D$ 维向量组成——1 个 `[class]` 嵌入加 $N$ 个 patch 的线性投影；$E_{\text{pos}}$ 是形状 $(N+1)\times D$ 的可学习表，逐位置相加（`[class]` 也有自己的位置编码）。
- 式 (2)(3)：“先 LN、再子层、最后加残差”，即 **pre-norm** 结构；$\ell$ 是第几层，$z'_\ell$ 是注意力子层之后的中间量。
- 式 (4)：取最后一层 `[class]` 位置的向量做 LN，得到图像表示 $y$，分类头作用在 $y$ 上。

**多头自注意力（附录 A，式 5–8）**。对输入序列 $z\in\mathbb{R}^{N\times D}$（对 ViT 来说序列长度是 $N+1$），先投影出 $q,k,v$，注意力权重由 query 与 key 的两两相似度给出，输出是对 value 的加权和：

$$
[q,k,v]=zU_{qkv},\quad U_{qkv}\in\mathbb{R}^{D\times3D_h}\qquad(5)
$$

$$
A=\mathrm{softmax}\big(qk^\top/\sqrt{D_h}\big),\quad A\in\mathbb{R}^{N\times N}\qquad(6)
$$

$$
\mathrm{SA}(z)=Av\qquad(7)
$$

多头（MSA）是并行运行 $k$ 个自注意力（“头”），把它们的输出拼接后再做一次投影；为了在改变 $k$ 时保持计算量和参数量不变，$D_h$ 通常取 $D/k$：

$$
\mathrm{MSA}(z)=[\mathrm{SA}_1(z);\ \mathrm{SA}_2(z);\ \cdots;\ \mathrm{SA}_k(z)]\,U_{msa},\quad U_{msa}\in\mathbb{R}^{k\cdot D_h\times D}\qquad(8)
$$

**一个具体的数字例子**（ViT-B/16，输入 $224\times224$ RGB 图像）：

| 量 | 含义 | 形状或数值 |
|---|---|---|
| $P,\ C,\ N$ | patch 边长、通道数、patch 数 | $16,\ 3,\ N=(224/16)^2=196$ |
| $x_p$ | 展平的 patch 序列 | $196\times768$（$P^2C=16\cdot16\cdot3=768$） |
| $E$ | patch 线性投影 | $768\times768$（$D=768$） |
| $E_{\text{pos}}$、$z_0$ | 位置编码、编码器输入 | $197\times768$（196 个 patch + 1 个 `[class]`） |
| $U_{qkv}$ | $q,k,v$ 投影（12 个头 $\times$ 每头 $D_h=64$） | $768\times2304$ |
| $A$ | 每个头的注意力矩阵 | $197\times197$ |
| MLP | 两层、GELU | $768\to3072\to768$ |
| $y$ | 图像表示（`[class]` 位置） | 768 维 |

（本表为本文按原文定义代入数字得到。）微调时若把分辨率提到 $384$，patch 大小不变，则 $N=(384/16)^2=576$，序列长度 577。

### 3.3 归纳偏置

论文强调：ViT 的图像特有归纳偏置比 CNN 少得多。

- CNN 里，**局部性**、**二维邻域结构**和**平移等变性**被烘焙进整个网络的每一层。
- ViT 里，只有 MLP 层是局部且平移等变的（它逐个 token 独立作用），而自注意力层是**全局**的。二维邻域结构被“非常节制地”使用：只有开头把图像切成 patch，以及微调时为适应不同分辨率调整位置编码这两处。
- 除此之外，初始化时的位置编码不携带任何 patch 的二维位置信息，patch 之间所有的空间关系都要从零学起。

### 3.4 混合架构

作为原始图像 patch 的替代，输入序列也可以由 CNN 的特征图构成。在这种**混合模型**里，式 (1) 中的 patch 嵌入投影 $E$ 作用在从 CNN 特征图上取出的 patch 上。特例是 patch 大小为 $1\times1$：此时只需把特征图的空间维度展平，再投影到 Transformer 维度。`[class]` 嵌入和位置编码照旧加入。

### 3.5 微调与更高分辨率

通常先在大数据集上预训练 ViT，再微调到较小的下游任务：去掉预训练的预测头，接上一个**零初始化**的 $D\times K$ 前馈层（$K$ 是下游类别数）。微调时用比预训练更高的分辨率往往有益。喂入更高分辨率的图像时，**patch 大小保持不变**，所以序列变长。ViT 可以处理任意长度的序列（受显存限制），但预训练的位置编码可能不再有意义，所以论文对预训练位置编码按其在原图中的位置做**二维插值**。这一分辨率调整和 patch 提取，是整个 ViT 里手工注入图像二维结构的唯一两处。

### 3.6 模型规格

模型配置基于 BERT：“Base”和“Large”直接沿用 BERT，另外加了更大的“Huge”。记号 ViT-L/16 表示“Large”规模、输入 patch 为 $16\times16$。注意 Transformer 的序列长度与 patch 边长的平方成反比，所以 patch 越小，计算越贵。

| ViT-Base | 12 | 768 | 3072 | 12 | 86M |

## 四、数据、基线与训练设置（原文第 4.1 节与附录 B）

### 4.1 数据集与基准

- **预训练数据**：ILSVRC-2012 ImageNet（1k 类、130 万张，下文简称 ImageNet）；它的超集 ImageNet-21k（21k 类、1400 万张）；JFT（18k 类、3.03 亿张高分辨率图像，Google 内部数据集）。预训练集都按 Kolesnikov 等人（2020）的做法针对下游任务的测试集做了去重。
- **迁移的下游任务**：ImageNet（原始验证集标签，以及清理过的 **ReaL** 标签）、CIFAR-10/100、Oxford-IIIT Pets、Oxford Flowers-102，预处理按 Kolesnikov 等人（2020）。
- **VTAB**（Visual Task Adaptation Benchmark）：19 项分类任务，考察**低数据**迁移——每项任务只用 1000 个训练样本。任务分三组：Natural（自然图像，如 Pets、CIFAR 等）、Specialized（医学和卫星图像）、Structured（需要几何理解的任务，如定位）。

### 4.2 模型变体与基线

- **ViT**：见表 1。
- **ResNet 基线**：用 ResNet，但把 Batch Normalization 换成 Group Normalization，并使用标准化卷积（standardized convolutions）；这些改动能提升迁移效果，修改后的模型记作 **ResNet (BiT)**。
- **混合模型**：把 ResNet 的中间特征图喂给 ViT，patch 大小取一个“像素”。为了试验不同的序列长度，有两种取法：（i）取普通 ResNet50 第 4 阶段的输出；（ii）去掉第 4 阶段，把同样数目的层放到第 3 阶段（总层数不变），取这个加长的第 3 阶段的输出。方式（ii）得到 4 倍长的序列，ViT 部分也更贵。

### 4.3 训练与微调

- **预训练**：所有模型（包括 ResNet）用 Adam（$\beta_1=0.9$、$\beta_2=0.999$），batch 4096，**权重衰减取较高的 0.1**（作者发现这对所有模型的迁移都有用）；线性学习率预热加线性衰减（预热 10k 步）。一反惯例，ResNet 也用 Adam 而不是 SGD，因为在这个设置下 Adam 略好（附录 D.1）。ImageNet 上还额外使用了全局范数 1 的梯度裁剪。预训练分辨率为 224。
- **正则化**：在 ImageNet 上从头训练时，强正则化是关键。Dropout（若使用）加在每个全连接层之后，但不包括 $q,k,v$ 投影，以及位置编码加到 patch 嵌入之后。混合模型的训练设置与对应的 ViT 完全相同。
- **微调**：所有模型用带动量 0.9 的 SGD，batch 512，余弦学习率衰减，无权重衰减，梯度裁剪（全局范数 1）。学习率在小范围内网格搜索（表 4）：用训练集的小子集当开发集（Pets 和 Flowers 取 10%，CIFAR 取 2%，ImageNet 取 1%），在剩余数据上训练；最终结果在整个训练集上训练、在各自的测试集上评测。ResNet 和混合模型用完全相同的设置，仅 ImageNet 的学习率扫描多加一个值 0.06；ResNet 还额外运行 Kolesnikov 等人（2020）的设置并在两者间取最好。除非另有说明，微调分辨率为 384。
- **ImageNet 上的最好结果（表 2）**：用更高的微调分辨率（ViT-L/16 用 512，ViT-H/14 用 518），并使用系数为 0.9999 的 Polyak 平均。
- **VTAB**：按 Kolesnikov 等人（2020）的协议，所有任务使用同一组超参：学习率 0.01、训练 2500 步（通过在两个学习率和两种训练计划上做小扫描，以 200 样本验证集上的 VTAB 得分选定）；不使用任务特定的输入分辨率，发现 ViT 在所有任务上都最受益于高分辨率（$384\times384$）。

### 4.4 评测指标

- **微调精度**：模型在各自数据集上微调之后的精度。
- **少样本（few-shot）线性精度**：求解一个正则化最小二乘回归问题，把一部分训练图像的（冻结的）表示映射到 $\{-1,1\}^K$ 的目标向量，可以闭式求得精确解。主要关注微调性能，但在微调成本太高、需要随训练在线快速评测时，会用线性少样本精度。

### 5.4 检视 ViT 内部（图 6、图 7、图 10、图 11）

为了理解 ViT 如何处理图像数据，作者分析了它的内部表示。

**第一层的嵌入滤波器**：ViT 的第一层把展平的 patch 线性投影到低维空间（式 1）。图 7 左给出学到的嵌入滤波器的前几个主成分，它们像是对每个 patch 内部精细结构的低维表示的合理基函数。

**位置编码**：投影之后加上学到的位置编码。图 7 中间的子图给出结果：模型学会在位置编码的相似性里编码图像内的**距离**——越近的 patch 位置编码越相似；还出现了**行列结构**——同一行/列的 patch 嵌入相似；对更大的网格有时还能看到正弦结构（附录 D）。位置编码学到了二维图像的拓扑，这也解释了为什么手工设计的二维感知嵌入变体没有带来改进（附录 D.4）。

**注意力距离**：自注意力让 ViT 在最低层也能整合整张图的信息。作者据此计算注意力权重在图像空间里整合信息的**平均距离**（图 7 右）；它类似 CNN 中的感受野大小。发现：一些头在最低层就已关注图像的大部分，说明模型确实利用了全局整合信息的能力；另一些头在低层的注意力距离一直很小，这种高度局部化的注意力在先用 ResNet 处理的混合模型里没那么明显（图 11），暗示它可能起着类似 CNN 早期卷积层的作用。此外，注意力距离随网络深度增加。

### 5.5 自监督（原文第 4.6 节、附录 B.1.2）

Transformer 在 NLP 里的成功不只来自可扩展性，也来自大规模自监督预训练。作者对**掩码 patch 预测**做了初步探索，模仿 BERT 的掩码语言建模。

- **做法**：把 50% 的 patch 嵌入破坏掉——其中 80% 替换为可学习的 `[mask]` 嵌入，10% 替换为随机的另一个 patch 嵌入，10% 保持不变（与 BERT 的做法很像）。然后用各个被破坏 patch 的表示去预测该 patch 的 **3 位平均颜色**（共 512 种颜色）。
- **训练设置**：在 JFT 上训练 100 万步（约 14 个 epoch），batch 4096，Adam，基础学习率 $2\cdot10^{-4}$，预热 10k 步，余弦衰减。
- **预测目标的尝试**：（1）只预测平均 3 位颜色（1 次 512 类预测）；（2）预测 patch 缩小成 $4\times4$ 后的 3 位颜色（16 次 512 类预测）；（3）用 L2 回归整个 patch（256 次对 3 个 RGB 通道的回归）。出人意料，这三种都表现不错，L2 略差；最终只报告方案（1），因为它的少样本性能最好。也试了 BERT 的 15% 破坏率，结果同样稍差。
- **结果**：自监督预训练后，较小的 ViT-B/16 在 ImageNet 上达到 79.9%，比从头训练（表 5 中 77.91）提高约 2 个点，但仍比有监督预训练低约 4 个点。对比学习预训练留作未来工作。
- 作者还指出，这种掩码 patch 预测不需要巨量预训练也不需要 JFT 这样的大数据集：10 万步之后收益递减，在 ImageNet 上预训练也看到类似的提升。

### 6.4 位置编码（D.4、表 8）

作者比较了几种编码空间信息的方式：

- **无位置信息**：把输入当成“一袋 patch”；
- **一维位置编码**：把输入看成按光栅顺序排列的 patch 序列（本文所有其他实验的默认）；
- **二维位置编码**：把输入看成二维的 patch 网格，学习两组各 $D/2$ 维的嵌入（X 嵌入和 Y 嵌入，分别对应两个坐标轴），再按 patch 的坐标把两者拼成最终的位置编码；
- **相对位置编码**：用 patch 之间的相对距离代替绝对位置，做一维相对注意力：对任一对（query，key/value），有偏移 $p_q-p_k$，每个偏移对应一个嵌入；再跑一个额外的注意力，用原来的 query（内容），但以相对位置嵌入作 key，把这个相对注意力的 logits 作为偏置加到主（基于内容的）注意力的 logits 上，再做 softmax。

除了编码方式，还试了三种把位置信息放进模型的位置：（1）在模型的 stem 里、送入 Transformer 编码器之前加（**默认**）；（2）每一层开头都学习并加上位置编码；（3）每层开头加一份学到的位置编码，各层**共享**。

**表 8：位置编码消融（ViT-B/16，ImageNet 5-shot 线性精度，以小数表示）。**

| 位置编码类型 | 默认/Stem（输入处加一次） | 每层 | 每层（层间共享） |
|---|---:|---:|---:|
| 无位置编码 | 0.61382 | N/A | N/A |
| 一维位置编码 | 0.64206 | 0.63964 | 0.64292 |
| 二维位置编码 | 0.64001 | 0.64046 | 0.64022 |
| 相对位置编码 | 0.64032 | N/A | N/A |

（原文表 8，第 17 页。）读法：有位置编码与没有之间差距很大（0.614 对 0.640 以上，约 2.6–2.9 个点），但各种位置编码方式之间几乎没有区别（有位置编码的各格最大差 0.0033，约 0.3 个点）。作者推测，因为 Transformer 编码器处理的是 patch 级输入而不是像素级输入，空间维度小得多（如 $14\times14$ 而不是 $224\times224$），在这个分辨率下学习表示空间关系对各种编码都同样容易，所以编码方式不那么重要。这是一个模型、一个评测指标下的结果。即便如此，网络学到的位置编码相似性的具体图案仍取决于训练超参数（见图 10）。

### 6.6 轴向注意力（D.6）

轴向注意力（Axial Attention）沿多维张量的单个轴依次做多次注意力，而不是对展平后的输入做一维注意力：每次注意力只沿某一个轴混合信息，其他轴上的信息保持独立。

- **AxialResNet**（Wang 等 2020b）：把 ResNet50 里所有 $3\times3$ 卷积替换成轴向自注意力（先行注意力再列注意力），并加上相对位置编码；作者自己实现作为基线。
- **Axial-ViT**：把 ViT 改成处理二维形状的输入，并使用轴向 Transformer 块：不是“自注意力 + MLP”，而是“行自注意力 + MLP”接着“列自注意力 + MLP”。

结果（原文图 13，本文未转录）：在 JFT 预训练、ImageNet 5-shot 线性评测下，Axial-ViT-B/32 和 Axial-ViT-B/16 都比相应的 ViT-B 性能更好，**但算力更多**——因为每个全局自注意力块被两个轴向块（一行一列）取代，虽然每次注意力的序列更短，但每个 Axial-ViT 块多了一个 MLP。AxialResNet 在精度/算力权衡上看起来合理，但朴素实现在 TPU 上极慢，所以未能做大规模实验（原文脚注：基于开源的 PyTorch 实现，精度能复现原论文，但在 TPU 上很慢）。

### 6.7 注意力距离与注意力图（D.7、D.8）

- **注意力距离**：为了理解 ViT 如何用自注意力整合整张图的信息，作者分析了不同层注意力权重所跨的平均距离（图 11，已在 5.4 节讲）：它类似 CNN 的感受野大小。在较低的层，注意力距离在不同头之间差别很大（有的头关注图像的大部分，有的只关注查询位置及其附近的小区域）；随着深度增加，所有头的注意力距离都变大；在网络的后半部分，大多数头广泛地关注各处 token。
- **注意力图**（图 6 和图 14）：用 **Attention Rollout**（Abnar & Zuidema 2020）计算：把 ViT-L/16 所有头的注意力权重取平均，再递归地乘上各层的权重矩阵，以计入各层中 token 之间注意力的混合。

### 6.8 ObjectNet（D.9）

在 ObjectNet 基准上评测旗舰模型 ViT-H/14（评测设置同 Kolesnikov 等人 2020）：top-5 精度 82.1%，top-1 精度 61.7%。

## 七、局限、证据边界与常见误读

**论文自己指出的局限与开放问题**（原文第 5 节）：

- 要把 ViT 用到其他视觉任务，如检测和分割；本文结果加上 Carion 等人（DETR）的结果，表明这个方向有前景，但这里没有做；
- 继续探索自监督预训练：初步实验有提升，但自监督与大规模有监督预训练之间仍有很大差距（79.9% 对约 84%）；
- 进一步扩大 ViT 规模很可能继续提升性能（缩放研究里没有看到饱和）。

**证据边界（读数字时要注意）**：

- **最好的结果依赖 JFT-300M**，它是 Google 内部数据集，外部无法获得；公开的 ImageNet-21k 上预训练也能得到很强的结果（ViT-L/16 在 ImageNet 上 85.30），但没有达到最高水平（88.55）。
- **小数据上 ViT 更弱**：ImageNet 从头训练时，ViT-L 比 ViT-B 还差（表 5：76.53 对 77.91），图 3、图 4 里 ViT 在小数据时低于 ResNet。“ViT 优于 CNN”只在预训练数据足够大时成立。
- **算力对比的口径**：TPUv3-core-days 与 exaFLOPs 来自作者自己的实现与估计，硬件、实现、训练计划不同就不能直接外推；论文自己也提示预训练效率还取决于训练计划、优化器、权重衰减等。受控的缩放研究只用 JFT-300M 预训练、迁移到 5 个自然图像分类数据集，且各模型用的是各自的学习率（表 3）。
- **统计显著性**：表 2 是三次微调的均值 ± 标准差；其他表（表 5、6、7、8）是单次结果，没有方差。位置编码消融（表 8）的差异只有约 0.3 个点，只在 ViT-B/16 一个模型、一个指标上做。
- **表间的小不一致**：表 5 与表 6 中同名模型的数字大体相同，但 ViT-H/14 有差别；表 4 与 B.1.1 对 ImageNet 学习率 0.06 的描述略有出入；图 4 横轴刻度写 10M/100M，正文写 9M/90M；参数量 307M（表 1）与按结构估算的约 304M 有出入。原文都没有说明原因。
- **可视化是定性的**：注意力图、位置编码相似性图、注意力距离图支持“ViT 学到了二维结构、能整合全局信息”，但不是因果证明。
- **自监督实验是初步的**，只对 ViT-B/16、一种掩码目标做了对比。

**常见误读**：

- “ViT 证明图像不需要任何空间先验”：错。切 patch 和微调时对位置编码做二维插值，本身仍注入了二维结构；论文也没有声称小数据上 ViT 天然优于 CNN，相反，数据规模依赖正是它的重要结论。
- “ViT 一定更省算力”：只有在大规模预训练、控制好其他因素的受控比较里，才约省 $2$–$4$ 倍；在 ImageNet 上从头训练时，ViT 需要强正则化（权重衰减 0.3、dropout 0.1、300 epoch），ViT-B/16 也只有 77.9%（表 5），处在 BiT ResNet 范围（图 3 阴影区，约 76.8 到 81.3，从图上读出）的下半部。
- “全局注意力在高分辨率下必然昂贵得无法使用”：理论上注意力代价随图像边长四次方增长，但实测里只有最大模型、最大分辨率才刚刚出现这种趋势（图 12）；不过序列长度仍随分辨率平方增长，论文的实验也只到 512 左右的输入，检测、分割等更高分辨率的任务留作未来工作。
- “必须用 `[class]` token”：D.3 表明 GAP 配合合适的学习率同样可以，差别主要在学习率。
- “二维位置编码更好”：表 8 显示几乎没有差别。
- “Large 比 Base 总是更好”：在 ImageNet 预训练时反而更差（图 3、表 5）。

## 八、复现检查清单

- **输入与 patch**：patch 按光栅顺序展平并线性投影（实现上等价于核大小和步长都等于 patch 边长的卷积，这是实现提示，不是论文原话）；序列长度 $N+1$，位置编码形状 $(N+1)\times D$。
- **编码器**：pre-norm（LN 在子层之前）、残差、MLP 隐藏维度 $4D$、GELU；头数 $k$ 与 $D_h=D/k$；最终对 `[class]` 输出做 LN。
- **头**：预训练用带 tanh 隐藏层的 MLP 头，微调换成零初始化的单个线性层。
- **分辨率**：微调用更高分辨率时保持 patch 大小，对位置编码做二维插值，并记录插值方法。
- **优化**：预训练用 Adam（$\beta=(0.9,0.999)$）、权重衰减 0.1、batch 4096、预热 10k 步；微调用 SGD（动量 0.9）、batch 512、余弦衰减、不用权重衰减、梯度裁剪 1；ImageNet 从头训练要用强正则（权重衰减 0.3、dropout 0.1、300 epoch、梯度裁剪）。
- **评测口径**：区分表 2（518/512 分辨率 + Polyak 平均）与表 5/6（384 分辨率）；少样本线性评测用闭式的正则化最小二乘解；预训练集对下游测试集做去重。
- **基线**：ResNet 基线要用 BiT 变体（Group Norm + 标准化卷积）和 Adam 预训练，否则比较不公平。
- **报告项**：同时报告 patch 大小、输入分辨率、序列长度，以及预训练数据和算力。
- **数据**：JFT-300M 不可得，复现趋势可用 ImageNet-21k；注意小数据下结论会变。

## 九、与相关论文的关系

- **Transformer**（[../transformer/论文中文解读.md](../transformer/论文中文解读.md)）：ViT 的编码器就是原版 Transformer 编码器，只是输入换成 patch 嵌入。
- **BERT**（[../bert/论文中文解读.md](../bert/论文中文解读.md)）：`[class]` token、Base/Large 规模、掩码预测的自监督（5.5 节）都来自 BERT 的做法。
- **ResNet**（[../resnet/论文中文解读.md](../resnet/论文中文解读.md)）：本文的主要对照，BiT 是它的大规模迁移学习版本。
- **Swin Transformer**（[../swin_transformer/论文中文解读.md](../swin_transformer/论文中文解读.md)）：针对 ViT 的单一尺度和全局注意力的二次成本，改用分层结构与移位窗口，恢复局部性和多尺度。
- **CLIP**（[../clip/论文中文解读.md](../clip/论文中文解读.md)）：把 ViT 作为图像编码器之一，改变监督信号（图文对比学习）。
- **DiT**（[../dit/论文中文解读.md](../dit/论文中文解读.md)）：把 ViT 风格的块用在扩散模型的去噪主干上。
