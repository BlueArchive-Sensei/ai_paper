# 论文概要：《Learning Transferable Visual Models From Natural Language Supervision》

## 基本信息

- 时间：2021
- 原文：[官方论文/页面](https://arxiv.org/abs/2103.00020)
- 本地：[PDF](paper.pdf) · [可检索文本](paper.txt) · [中文精读](论文中文解读.md)

## 一句话结论

CLIP 用海量图文对的对比学习把图像与自然语言投到同一空间，使文本 prompt 可直接充当零样本分类器。

## 核心方法

一个 image encoder 与一个 text encoder 生成归一化向量，对 batch 内 N×N 相似度做双向交叉熵；可学习 temperature 控制分布锐度。下游类别写成多种自然语言模板并做 prompt ensemble。

## 历史影响

CLIP 把开放词汇视觉、跨模态检索与生成模型条件编码推向主流，成为多模态 foundation model 的通用组件。

## 局限

网络图文弱标签含偏见与噪声；零样本结果高度依赖 prompt engineering。相似度模型不等于细粒度定位、计数或可靠视觉推理。

## 阅读衔接

与 ViT 连读理解视觉 encoder；与 Latent Diffusion 连读理解文本条件；SAM 则用 promptable mask 接口解决分割。
